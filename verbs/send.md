# Verbo: SEND

## Traduções principais
- enviar
- mandar

### Informações gerais

**Outras traduções**
- transmitir
- despachar
- encaminhar
- remeter

#### Palavras da mesma família

- send → enviar
- sent → enviado
- sender → remetente
- sending → enviando
- shipment → remessa

#### CEFR
- A1

#### Relevância para TI
- Extremamente usado

#### Tipo de verbo
- Irregular

### Pronúncia (IPA – General American)

- Presente: **send** → /send/
- Presente (3ª pessoa): **sends** → /sendz/
- Passado: **sent** → /sent/
- Particípio: **sent** → /sent/
- Forma em **-ING**: **sending** → /ˈsendɪŋ/

### Phrasal verbs

- send back
- send out
- send in
- send over

### Forma em -ING

**send → sending**

O verbo apenas recebe **-ING**.

Exemplos:

- I am sending an email.
  (Estou enviando um e-mail.)

- She is sending the report.
  (Ela está enviando o relatório.)

## Frases (tempo verbal)

### Presente (1ª pessoa)

I send emails every day.

(Eu envio e-mails todos os dias.)

### Presente (3ª pessoa)

She sends reports to the team.

(Ela envia relatórios para a equipe.)

### Passado

I sent the file yesterday.

(Eu enviei o arquivo ontem.)

### Futuro

I will send the document later.

(Eu enviarei o documento mais tarde.)

### Particípio (Present Perfect)

I have sent the message.

(Eu enviei a mensagem.)

## Estruturas importantes

### Estrutura principal

**send + objeto**

Exemplos:

- Send the file.
  (Envie o arquivo.)

- I sent the email.
  (Eu enviei o e-mail.)

- She sent the report.
  (Ela enviou o relatório.)

### Outras formas comuns

#### send something to someone

- I sent the document to John.
  (Eu enviei o documento para o John.)

- She sent the file to the client.
  (Ela enviou o arquivo ao cliente.)

- We sent the report to management.
  (Enviamos o relatório para a gerência.)

#### send an email

- Please send an email.
  (Por favor, envie um e-mail.)

- I sent an email this morning.
  (Enviei um e-mail esta manhã.)

#### send data

- The application sends data to the server.
  (A aplicação envia dados para o servidor.)

- Sensors send information continuously.
  (Sensores enviam informações continuamente.)

## Uso com outros verbos

### Usa -ING?

✔ Sim

Exemplos:

- Sending reports takes time.
  (Enviar relatórios leva tempo.)

- I enjoy sending updates to the team.
  (Gosto de enviar atualizações para a equipe.)

- The application is sending requests.
  (A aplicação está enviando requisições.)

### Usa TO + infinitivo?

✔ Sim

Exemplos:

- I need to send an email.
  (Preciso enviar um e-mail.)

- We want to send the report today.
  (Queremos enviar o relatório hoje.)

- She plans to send the files tomorrow.
  (Ela planeja enviar os arquivos amanhã.)

### Preposição obrigatória?

A mais comum é:

- **send something to someone**

Exemplos:

- Send the report to the manager.
  (Envie o relatório ao gerente.)

- We sent the package to the customer.
  (Enviamos o pacote ao cliente.)

## Frases extras (uso real)

- The application sends notifications automatically.
  (A aplicação envia notificações automaticamente.)

- Please send me the latest version of the document.
  (Por favor, envie-me a versão mais recente do documento.)

- The server sends data to multiple clients.
  (O servidor envia dados para vários clientes.)

- We sent the deployment report after the release.
  (Enviamos o relatório de implantação após a liberação.)

- Developers often send logs to support teams.
  (Desenvolvedores frequentemente enviam logs para equipes de suporte.)

## Combinações mais comuns (Collocations)

### send an email

### send a message

  (Por favor, envie o arquivo novamente.)

  (A API envia dados em formato JSON.)

  (Enviamos o relatório na sexta-feira.)

## Expressões comuns

- send an email

- send someone a link

## Erros comuns

❌ I have sended the file.

✔ I have sent the file.

O particípio correto é **sent**.

---

❌ Yesterday I sended an email.

✔ Yesterday I sent an email.

O passado simples é **sent**.

---

❌ She send reports every day.

✔ She sends reports every day.

Na 3ª pessoa do singular, adiciona-se **-s**.

## Observações importantes

- As formas corretas são: **send → sent → sent**.
- A estrutura mais comum é **send something to someone**.
- Em TI, aparece constantemente em expressões como **send an email**, **send data**, **send requests** e **send notifications**.
