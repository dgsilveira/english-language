# Verbo: RUN

## Traduções principais
- correr
- executar

---

## Informações gerais

### Outras traduções

- funcionar
- operar
- administrar
- gerenciar
- executar um programa ou processo

### Palavras da mesma família

- run → corrida / execução
- runner → corredor
- running → correndo / executando
- runtime → tempo de execução
- rundown → resumo

### CEFR

- A1

### Relevância para TI

- Extremamente usado

### Tipo de verbo

- Irregular

---

## Pronúncia (IPA – General American)

- Presente: **run** → /rʌn/
- Presente (3ª pessoa): **runs** → /rʌnz/
- Passado: **ran** → /ræn/
- Particípio: **run** → /rʌn/
- Forma em **-ING**: **running** → /ˈrʌnɪŋ/

---

## Forma em -ING

**run → running**

A consoante final é duplicada.

- run → running

Exemplos:

- I am running a script.
  (Estou executando um script.)

- The application is running.
  (A aplicação está em execução.)

---

## Frases (tempo verbal)

### Presente (1ª pessoa)

I run every morning.

(Eu corro todas as manhãs.)

### Presente (3ª pessoa)

She runs a small business.

(Ela administra uma pequena empresa.)

### Passado

I ran the command yesterday.

(Eu executei o comando ontem.)

### Futuro

I will run the test again.

(Eu executarei o teste novamente.)

### Particípio (Present Perfect)

I have run this program before.

(Eu já executei este programa antes.)

---

## Estruturas importantes

### Estrutura principal

**run + objeto**

Exemplos:

- Run a program.
  (Execute um programa.)

- Run a test.
  (Execute um teste.)

- Run a report.
  (Execute um relatório.)

### Outras formas comuns

#### run a program

- Run the application.
  (Execute a aplicação.)

- I ran the script successfully.
  (Executei o script com sucesso.)

#### run a test

- We ran several tests.
  (Executamos vários testes.)

- The team runs automated tests daily.
  (A equipe executa testes automatizados diariamente.)

#### run a business

- She runs the company.
  (Ela administra a empresa.)

- They run a successful startup.
  (Eles administram uma startup de sucesso.)

#### run on

- The software runs on Linux.
  (O software roda em Linux.)

- The application runs on Windows.
  (A aplicação roda no Windows.)

---

## Uso com outros verbos

### Usa -ING?

✅ Sim.

Exemplos:

- Running tests improves software quality.
  (Executar testes melhora a qualidade do software.)

- I enjoy running experiments.
  (Gosto de executar experimentos.)

- The system is running normally.
  (O sistema está funcionando normalmente.)

### Usa TO + infinitivo?

✅ Sim.

Exemplos:

- I need to run the report.
  (Preciso executar o relatório.)

- We want to run more tests.
  (Queremos executar mais testes.)

- She plans to run the migration tonight.
  (Ela planeja executar a migração hoje à noite.)

---

## Preposição obrigatória?

Não possui.

Mas são comuns:

- run on
- run into
- run through

Exemplos:

- Run on Linux.
  (Rodar em Linux.)

- Run into problems.
  (Encontrar problemas.)

## Frases extras (uso real)

  (A aplicação está rodando em produção.)

  (Desenvolvedores devem executar testes antes da implantação.)

  (O banco de dados roda em um servidor dedicado.)

## Erros comuns

❌ I have ran the script.

✔ I have run the script.

O particípio correto é **run**.

---

❌ Yesterday I run the test.

✔ Yesterday I ran the test.

No passado simples, utiliza-se **ran**.

---

❌ She run the application daily.

✔ She runs the application daily.

Na 3ª pessoa do singular, adiciona-se **-s**.

---

## Observações importantes

- As formas do verbo são:

| Forma | Verbo |
|---------|---------|
| Presente | run |
| Passado | ran |
| Particípio | run |

- Em TI, **run** é um dos verbos mais usados:

  - run a program
  - run a command
  - run a script
  - run tests
  - run a deployment

### Frase clássica

**Run the tests before deploying the application.**

➡️ **Execute os testes antes de implantar a aplicação.**
