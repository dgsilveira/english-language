# Verbo: STOP

## Traduções principais
- parar
- interromper

### Informações gerais

**Outras traduções**
- cessar
- impedir
- terminar
- deixar de fazer algo

#### Palavras da mesma família

- stop → parada
- stopped → parado
- stopping → parada / interrompendo
- stopover → escala
- stopper → bloqueador

#### CEFR
- A1

#### Relevância para TI
- Muito usado

#### Tipo de verbo

- Regular

### Pronúncia (IPA – General American)

- Presente: **stop** → /stɑːp/
- Presente (3ª pessoa): **stops** → /stɑːps/
- Passado: **stopped** → /stɑːpt/
- Particípio: **stopped** → /stɑːpt/
- Forma em **-ING**: **stopping** → /ˈstɑːpɪŋ/

### Phrasal verbs

- stop by
- stop over
- stop off
- stop up

### Forma em -ING

**stop → stopping**

A consoante final é duplicada.

- stop → stopping

Exemplos:

- I am stopping the service.
  (Estou interrompendo o serviço.)

- She is stopping the process.
  (Ela está interrompendo o processo.)

## Frases (tempo verbal)

### Presente (1ª pessoa)

I stop working at 6 p.m.

(Eu paro de trabalhar às 18h.)

### Presente (3ª pessoa)

She stops the application when necessary.

(Ela para a aplicação quando necessário.)

### Passado

I stopped the deployment.

(Eu interrompi a implantação.)

### Futuro

I will stop the service.

(Eu interromperei o serviço.)

### Particípio (Present Perfect)

I have stopped the process.

(Eu interrompi o processo.)

## Estruturas importantes

### Estrutura principal

**stop + objeto**

Exemplos:

- Stop the service.
  (Pare o serviço.)

- I stopped the process.
  (Eu interrompi o processo.)

- She stopped the application.
  (Ela parou a aplicação.)

### Outras formas comuns

#### stop + ING

Parar uma atividade.

- I stopped working.
  (Eu parei de trabalhar.)

- She stopped smoking.
  (Ela parou de fumar.)

- We stopped testing for the day.
  (Paramos os testes por hoje.)

#### stop to + verbo

Parar para fazer outra atividade.

- I stopped to answer an email.
  (Parei para responder um e-mail.)

- She stopped to help a colleague.
  (Ela parou para ajudar um colega.)

- We stopped to review the logs.
  (Paramos para revisar os logs.)

#### stop someone from + ING

- The firewall stopped attackers from accessing the server.
  (O firewall impediu atacantes de acessar o servidor.)

- This rule stops users from making changes.
  (Esta regra impede os usuários de fazer alterações.)

## Uso com outros verbos

### Usa -ING?

✔ Sim

Quando significa interromper uma atividade.

Exemplos:

- I stopped using that tool.
  (Parei de usar aquela ferramenta.)

- She stopped working late.
  (Ela parou de trabalhar até tarde.)

- We stopped deploying on Fridays.
  (Paramos de implantar às sextas-feiras.)

### Usa TO + infinitivo?

✔ Sim

Quando significa fazer uma pausa para outra ação.

Exemplos:

- I stopped to read the message.
  (Parei para ler a mensagem.)

- She stopped to check the logs.
  (Ela parou para verificar os logs.)

- We stopped to discuss the problem.
  (Paramos para discutir o problema.)

### Preposição obrigatória?

A mais comum é:

- **stop someone from + ING**

Exemplos:

- The system stopped users from logging in.
  (O sistema impediu os usuários de fazer login.)

- This update stopped the application from crashing.
  (Esta atualização impediu a aplicação de falhar.)

## Frases extras (uso real)

- The administrator stopped the service before maintenance.
  (O administrador interrompeu o serviço antes da manutenção.)

- We stopped the deployment after finding a critical bug.
  (Interrompemos a implantação após encontrar um bug crítico.)

- The application suddenly stopped responding.
  (A aplicação parou de responder repentinamente.)

- Developers stopped using the old framework.
  (Os desenvolvedores pararam de usar o framework antigo.)

- The update stopped the recurring error.
  (A atualização eliminou o erro recorrente.)

## Combinações mais comuns (Collocations)

### stop working

  (Meu notebook parou de funcionar de repente.)

### stop a service

- The administrator stopped the service.
  (O administrador interrompeu o serviço.)

### stop a process

  (Interrompemos o processo imediatamente.)

### stop responding

  (A aplicação parou de responder.)

### stop using

  (A equipe parou de usar aquela ferramenta.)

## Erros comuns

❌ I stopped to work at 6 p.m.

✔ I stopped working at 6 p.m.

Use **stop + ING** para indicar uma atividade que foi interrompida.

---

❌ I stopped working to answer the phone. *(significado diferente)*

✔ I stopped to answer the phone.

Use **stop to + verbo** quando você faz uma pausa para realizar outra ação.

---

❌ She stop the service.

✔ She stops the service.

Na 3ª pessoa do singular, adiciona-se **-s**.

## Observações importantes

- A diferença entre **stop + ING** e **stop to + verbo** é uma das mais importantes do inglês.
- **Stop + ING** = parar uma atividade; **stop to + verbo** = parar para fazer outra atividade.
- Em TI, é muito comum em expressões como **stop a service**, **stop a process**, **stop responding** e **stop using a tool**.
