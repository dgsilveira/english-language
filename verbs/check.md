## Verbo: CHECK

### Traduções principais
- verificar
- conferir

### Informações gerais

**Outras traduções**
- checar
- examinar
- inspecionar
- confirmar

#### Palavras da mesma família

- check → verificação / cheque
- checklist → lista de verificação
- checked → verificado
- checking → verificação
- checker → verificador

#### CEFR
- A1

#### Relevância para TI
- Muito usado

#### Tipo de verbo
- Regular

### Pronúncia (IPA – General American)

- Presente: **check** → /tʃek/
- Presente (3ª pessoa): **checks** → /tʃeks/
- Passado: **checked** → /tʃekt/
- Particípio: **checked** → /tʃekt/
- Forma em **-ING**: **checking** → /ˈtʃekɪŋ/

### Phrasal verbs

- check in
- check out
- check up on
- check off
- check back

### Forma em -ING

**check → checking**

O verbo apenas recebe **-ING**.

- check → checking

Pronúncia:

- checking → /ˈtʃekɪŋ/

Exemplos:

- I am checking the logs.
  (Estou verificando os logs.)

- She is checking the configuration.
  (Ela está verificando a configuração.)

## Frases (tempo verbal)

### Presente (1ª pessoa)

I check my email every morning.

(Eu verifico meus e-mails todas as manhãs.)

### Presente (3ª pessoa)

She checks the system regularly.

(Ela verifica o sistema regularmente.)

### Passado

I checked the server yesterday.

(Eu verifiquei o servidor ontem.)

### Futuro

I will check the report later.

(Eu verificarei o relatório mais tarde.)

### Particípio (Present Perfect)

I have checked the configuration.

(Eu verifiquei a configuração.)

## Estruturas importantes

### Estrutura principal

**check + objeto**

Exemplos:

- Check the report.
  (Verifique o relatório.)

- I checked the logs.
  (Eu verifiquei os logs.)

- She checked the server.
  (Ela verificou o servidor.)

### Outras formas comuns

#### check + if/whether + oração

Usado para confirmar informações.

- Check if the service is running.
  (Verifique se o serviço está em execução.)

- I checked whether the file existed.
  (Eu verifiquei se o arquivo existia.)

- She checked if the update was successful.
  (Ela verificou se a atualização foi bem-sucedida.)

#### check + for + substantivo

Usado para procurar algo específico.

- Check for updates.
  (Verifique se há atualizações.)

- We checked for errors.
  (Verificamos se havia erros.)

- The system checks for malware.
  (O sistema verifica a existência de malware.)

#### check with + pessoa

Usado para confirmar algo com alguém.

- Check with your manager.
  (Confirme com seu gerente.)

- I checked with the client.
  (Eu confirmei com o cliente.)

- She checked with the support team.
  (Ela confirmou com a equipe de suporte.)

## Uso com outros verbos

### Usa -ING?

- ✔ Sim

Principalmente após preposições.

Exemplos:

- Thank you for checking the report.
  (Obrigado por verificar o relatório.)

- She is responsible for checking the logs.
  (Ela é responsável por verificar os logs.)

- We learned by checking the documentation.
  (Aprendemos verificando a documentação.)

### Usa TO + infinitivo?

- ✔ Sim

Muito comum para indicar finalidade.

Exemplos:

- I checked to see if everything was working.
  (Eu verifiquei para ver se tudo estava funcionando.)

- She checked to confirm the information.
  (Ela verificou para confirmar a informação.)

- We checked to make sure the deployment succeeded.
  (Verificamos para garantir que a implantação foi bem-sucedida.)

### Preposição obrigatória?

Não possui preposição obrigatória.

As mais comuns são:

- for
- with

Exemplos:

- Check for updates.
  (Verifique se há atualizações.)

- I checked with the manager.
  (Eu confirmei com o gerente.)

- The application checks for errors automatically.
  (A aplicação verifica erros automaticamente.)

## Frases extras (uso real)

- Please check the logs before restarting the service.
  (Por favor, verifique os logs antes de reiniciar o serviço.)

- I need to check the database connection.
  (Preciso verificar a conexão com o banco de dados.)

- The developer checked the API response.
  (O desenvolvedor verificou a resposta da API.)

- We should check for security vulnerabilities.
  (Devemos verificar vulnerabilidades de segurança.)

- She checked the documentation before making changes.
  (Ela verificou a documentação antes de fazer alterações.)

## Combinações mais comuns (Collocations)

### check the logs

- Always check the logs when troubleshooting.
  (Sempre verifique os logs ao solucionar problemas.)

### check for errors

- The system checks for errors automatically.
  (O sistema verifica erros automaticamente.)

### check the status

- Please check the status of the deployment.
  (Por favor, verifique o status da implantação.)

### check the configuration

- The administrator checked the configuration.
  (O administrador verificou a configuração.)

### check the documentation

- Developers should check the documentation first.
  (Os desenvolvedores devem verificar a documentação primeiro.)

## Expressões comuns

- check for updates
- check the status
- check with someone
- check again
- double-check

## Erros comuns

❌ I checked about the problem.

✔ I checked the problem.

✔ I checked for information about the problem.

Normalmente **check** não usa **about** diretamente.

---

❌ Check if is working.

✔ Check if it is working.

Em inglês, o sujeito normalmente deve ser informado.

---

❌ I have check the logs.

✔ I have checked the logs.

No Present Perfect, utiliza-se o particípio **checked**.

## Observações importantes

- **Check** é um dos verbos mais usados em ambientes profissionais e de TI.
- A estrutura **check for + substantivo** é extremamente comum para procurar erros, atualizações e problemas.
- A expressão **double-check** significa verificar novamente para garantir que algo esteja correto.
