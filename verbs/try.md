# Verbo: TRY

## Traduções principais
- tentar
- experimentar

### Informações gerais

**Outras traduções**
- esforçar-se
- testar
- procurar fazer algo
- dar uma chance

#### Palavras da mesma família

- try → tentativa
- tried → tentado
- trying → tentando
- retry → tentar novamente
- trial → teste / tentativa

#### CEFR
- A1

#### Relevância para TI
- Muito usado

#### Tipo de verbo

- Regular

### Pronúncia (IPA – General American)

- Presente: **try** → /traɪ/
- Presente (3ª pessoa): **tries** → /traɪz/
- Passado: **tried** → /traɪd/
- Particípio: **tried** → /traɪd/
- Forma em **-ING**: **trying** → /ˈtraɪɪŋ/

### Phrasal verbs

- try on
- try out
- try for
- try out for

### Forma em -ING

**try → trying**

O **y** é mantido antes de adicionar **-ING**.

- try → trying

Exemplos:

- I am trying to solve the problem.
  (Estou tentando resolver o problema.)

- She is trying a new tool.
  (Ela está experimentando uma nova ferramenta.)

## Frases (tempo verbal)

### Presente (1ª pessoa)

I try to improve every day.

(Eu tento melhorar todos os dias.)

### Presente (3ª pessoa)

She tries to learn new skills.

(Ela tenta aprender novas habilidades.)

### Passado

I tried a different solution.

(Eu tentei uma solução diferente.)

### Futuro

I will try again tomorrow.

(Eu tentarei novamente amanhã.)

### Particípio (Present Perfect)

I have tried that approach before.

(Eu já tentei essa abordagem antes.)

## Estruturas importantes

### Estrutura principal

**try to + verbo**

Exemplos:

- Try to help.
  (Tente ajudar.)

- I tried to fix the issue.
  (Eu tentei corrigir o problema.)

- She tries to stay focused.
  (Ela tenta permanecer focada.)

### Outras formas comuns

#### try + objeto

- I tried the new application.
  (Eu experimentei a nova aplicação.)

- She tried a different method.
  (Ela experimentou um método diferente.)

- We tried the latest version.
  (Nós experimentamos a versão mais recente.)

#### try + ING

Usado para experimentar algo como teste.

- Try restarting the service.
  (Tente reiniciar o serviço.)

- Try updating the application.
  (Tente atualizar a aplicação.)

- Try using a different browser.
  (Tente usar um navegador diferente.)

#### try out

- We tried out a new framework.
  (Experimentamos um novo framework.)

- She tried out the beta version.
  (Ela experimentou a versão beta.)

## Uso com outros verbos

### Usa -ING?

✔ Sim

Quando significa experimentar uma solução ou método.

Exemplos:

- Try restarting the computer.
  (Tente reiniciar o computador.)

- Try using another password.
  (Tente usar outra senha.)

- We tried changing the configuration.
  (Tentamos alterar a configuração.)

### Usa TO + infinitivo?

✔ Sim

Quando significa fazer esforço para realizar algo.

Exemplos:

- I try to learn every day.
  (Eu tento aprender todos os dias.)

- She tried to solve the issue.
  (Ela tentou resolver o problema.)

- We are trying to improve performance.
  (Estamos tentando melhorar o desempenho.)

### Preposição obrigatória?

Não possui.

Mas são comuns:

- try out
- try for

Exemplos:

- Try out the new feature.
  (Experimente o novo recurso.)

- He is trying for a promotion.
  (Ele está tentando conseguir uma promoção.)

## Frases extras (uso real)

- We tried to reproduce the bug before fixing it.
  (Tentamos reproduzir o bug antes de corrigi-lo.)

- Developers should try different approaches when debugging.
  (Desenvolvedores devem tentar abordagens diferentes ao depurar.)

- I tried using a different API endpoint.
  (Eu tentei usar um endpoint de API diferente.)

- The team is trying to reduce deployment time.
  (A equipe está tentando reduzir o tempo de implantação.)

- Have you tried restarting the application?
  (Você já tentou reiniciar a aplicação?)

  (Estamos tentando resolver o problema.)

## Expressões comuns

## Erros comuns

❌ I have try this solution before.

✔ I have tried this solution before.

No Present Perfect, utiliza-se **tried**.

---

❌ She try to solve the problem.

✔ She tries to solve the problem.

Na 3ª pessoa do singular, o **y** muda para **ies**.

---

❌ I try solve the issue.

✔ I try to solve the issue.

Após **try**, normalmente utiliza-se **to + verbo** quando significa fazer um esforço para realizar algo.

## Observações importantes

- A diferença entre **try to do** e **try doing** é uma das mais importantes deste verbo.
- **Try to do** = fazer esforço para conseguir algo; **try doing** = experimentar uma possível solução.
- Em TI, aparecem frequentemente expressões como **try again**, **try using**, **try to solve** e **try out a new tool**.
