# Verbo: WRITE

## Traduções principais
- escrever

### Informações gerais

**Outras traduções**
- redigir
- anotar
- registrar
- elaborar um texto

#### Palavras da mesma família

- write → escrever
- writer → escritor
- writing → escrita / escrevendo
- written → escrito
- rewrite → reescrever

#### CEFR
- A1

#### Relevância para TI
- Extremamente usado

#### Tipo de verbo

- Irregular

### Pronúncia (IPA – General American)

- Presente: **write** → /raɪt/
- Presente (3ª pessoa): **writes** → /raɪts/
- Passado: **wrote** → /roʊt/
- Particípio: **written** → /ˈrɪtən/
- Forma em **-ING**: **writing** → /ˈraɪtɪŋ/

### Phrasal verbs

- write down
- write up
- write back
- write off

### Forma em -ING

**write → writing**

O verbo perde o **e** final antes de adicionar **-ING**.

Exemplos:

- I am writing an email.
  (Estou escrevendo um e-mail.)

- She is writing documentation.
  (Ela está escrevendo documentação.)

## Frases (tempo verbal)

### Presente (1ª pessoa)

I write reports every week.

(Eu escrevo relatórios toda semana.)

### Presente (3ª pessoa)

She writes technical articles.

(Ela escreve artigos técnicos.)

### Passado

I wrote the documentation yesterday.

(Eu escrevi a documentação ontem.)

### Futuro

I will write the report tomorrow.

(Eu escreverei o relatório amanhã.)

### Particípio (Present Perfect)

I have written several guides.

(Eu escrevi vários guias.)

## Estruturas importantes

### Estrutura principal

**write + objeto**

Exemplos:

- Write a report.
  (Escreva um relatório.)

- I wrote an email.
  (Eu escrevi um e-mail.)

- She writes documentation.
  (Ela escreve documentação.)

### Outras formas comuns

#### write about

- I wrote about cybersecurity.
  (Eu escrevi sobre segurança cibernética.)

- She writes about technology.
  (Ela escreve sobre tecnologia.)

- We wrote about the incident.
  (Nós escrevemos sobre o incidente.)

#### write down

- Write down your ideas.
  (Anote suas ideias.)

- I wrote down the requirements.
  (Eu anotei os requisitos.)

- She wrote down the meeting notes.
  (Ela anotou as notas da reunião.)

#### write to someone

- I wrote to the customer.
  (Eu escrevi para o cliente.)

- She wrote to the support team.
  (Ela escreveu para a equipe de suporte.)

- We wrote to management.
  (Nós escrevemos para a gerência.)

## Uso com outros verbos

### Usa -ING?

✔ Sim

Exemplos:

- Writing documentation is important.
  (Escrever documentação é importante.)

- I enjoy writing code.
  (Gosto de escrever código.)

- They are writing a proposal.
  (Eles estão escrevendo uma proposta.)

### Usa TO + infinitivo?

✔ Sim

Exemplos:

- I want to write a book.
  (Quero escrever um livro.)

- We need to write better documentation.
  (Precisamos escrever documentação melhor.)

- She plans to write an article.
  (Ela planeja escrever um artigo.)

### Preposição obrigatória?

Não possui.

Mas são comuns:

- write about
- write to
- write down

Exemplos:

- Write about the project.
  (Escreva sobre o projeto.)

- Write to the client.
  (Escreva para o cliente.)

## Frases extras (uso real)

- Developers write code every day.
  (Desenvolvedores escrevem código todos os dias.)

  (Escrevemos um relatório detalhado do incidente.)

  (O engenheiro escreveu documentação para a nova API.)

- Please write down the deployment steps.

  (Ela escreve artigos técnicos regularmente.)

## Erros comuns

❌ I have wrote the report.

✔ I have written the report.

O particípio correto é **written**.

---

❌ Yesterday I written an email.

✔ Yesterday I wrote an email.

No passado simples, utiliza-se **wrote**.

---

❌ She write documentation.

✔ She writes documentation.

Na 3ª pessoa do singular, adiciona-se **-s**.

## Observações importantes

- As formas corretas são: **write → wrote → written**.
- Um erro muito comum é usar **wrote** no lugar de **written** no Present Perfect.
- Em TI, aparece constantemente em expressões como **write code**, **write documentation**, **write a report** e **write an email**.
