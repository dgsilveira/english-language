## Verbo: DEBUG

### Traduções principais
- depurar
- corrigir erros

### Informações gerais

**Outras traduções**
- identificar falhas
- localizar bugs
- solucionar problemas de software
- analisar erros de execução

#### Palavras da mesma família

- debug → depuração
- debugging → depuração / depurando
- debugger → depurador
- debugged → depurado
- bug → erro de software

#### CEFR
- B2

#### Relevância para TI
- Extremamente usado

#### Tipo de verbo
- Regular

### Pronúncia (IPA – General American)

- Presente: **debug** → /diːˈbʌɡ/
- Presente (3ª pessoa): **debugs** → /diːˈbʌɡz/
- Passado: **debugged** → /diːˈbʌɡd/
- Particípio: **debugged** → /diːˈbʌɡd/
- Forma em **-ING**: **debugging** → /diːˈbʌɡɪŋ/

### Phrasal verbs

Não existem phrasal verbs relevantes derivados diretamente de **debug**.

### Forma em -ING

**debug → debugging**

A consoante final é duplicada antes de adicionar **-ING**.

- debug → debugging

Pronúncia:

- debugging → /diːˈbʌɡɪŋ/

Exemplos:

- I am debugging the application.
  (Estou depurando a aplicação.)

- She is debugging a production issue.
  (Ela está depurando um problema em produção.)

## Frases (tempo verbal)

### Presente (1ª pessoa)

I debug software applications.

(Eu depuro aplicações de software.)

### Presente (3ª pessoa)

She debugs complex systems.

(Ela depura sistemas complexos.)

### Passado

I debugged the issue yesterday.

(Eu depurei o problema ontem.)

### Futuro

I will debug the application tomorrow.

(Eu depurarei a aplicação amanhã.)

### Particípio (Present Perfect)

I have debugged the problem.

(Eu depurei o problema.)

## Estruturas importantes

### Estrutura principal

**debug + objeto**

Exemplos:

- Debug the application.
  (Depure a aplicação.)

- I debugged the service.
  (Eu depurei o serviço.)

- She debugged the API.
  (Ela depurou a API.)

### Outras formas comuns

#### debug a bug

  (Depuramos um bug crítico.)

  (Ela depurou o problema de login.)

#### debug code

- I debugged the code.
  (Eu depurei o código.)

  (Eles depuraram o script.)

#### debug an issue

- The engineer debugged the issue quickly.
  (O engenheiro depurou o problema rapidamente.)

- We are debugging a performance issue.
  (Estamos depurando um problema de desempenho.)

## Uso com outros verbos

### Usa -ING?

- ✔ Sim

Exemplos:

- Debugging takes patience.
  (Depurar exige paciência.)

- I enjoy debugging applications.
  (Eu gosto de depurar aplicações.)

- She is debugging the database connection.
  (Ela está depurando a conexão com o banco de dados.)

### Usa TO + infinitivo?

- ✔ Sim

Exemplos:

- I need to debug this application.
  (Preciso depurar esta aplicação.)

- We want to debug the service.
  (Queremos depurar o serviço.)

- She plans to debug the API tomorrow.
  (Ela planeja depurar a API amanhã.)

Não possui preposição obrigatória.

Exemplos:

  (Depure o código.)

  (Depure a aplicação.)

  (Depure o problema.)

## Erros comuns

❌ I have debug the application.

✔ I have debugged the application.

No Present Perfect, utiliza-se o particípio **debugged**.

---

❌ She debug the code.

✔ She debugs the code.

Na 3ª pessoa do singular, adiciona-se **-s**.

---

❌ We are debuging the issue.

✔ We are debugging the issue.

A grafia correta é **debugging** (com duas letras **g**).

## Observações importantes

- **Debug** é um dos verbos mais importantes na área de desenvolvimento de software.
- Significa localizar, analisar e corrigir erros (bugs) em sistemas, aplicações ou códigos.
- Expressões como **debug code**, **debug an issue**, **debug a service** e **debug a production problem** são extremamente comuns em TI.
- A palavra **debugging** aparece frequentemente em entrevistas técnicas, documentação e atividades diárias de programação.
