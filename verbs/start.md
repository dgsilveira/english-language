# Verbo: START

## Traduções principais
- começar
- iniciar

### Informações gerais

**Outras traduções**
- dar início
- colocar em funcionamento
- partir
- arrancar (motor, sistema, processo)

#### Palavras da mesma família

- start → início
- starter → iniciador
- started → iniciado
- starting → iniciando
- startup → startup / inicialização

#### CEFR
- A1

#### Relevância para TI
- Extremamente usado

#### Tipo de verbo

- Regular

### Pronúncia (IPA – General American)

- Presente: **start** → /stɑːrt/
- Presente (3ª pessoa): **starts** → /stɑːrts/
- Passado: **started** → /ˈstɑːrtɪd/
- Particípio: **started** → /ˈstɑːrtɪd/
- Forma em **-ING**: **starting** → /ˈstɑːrtɪŋ/

### Phrasal verbs

- start up
- start out
- start over
- start off

### Forma em -ING

**start → starting**

O verbo apenas recebe **-ING**.

Exemplos:

- I am starting a new project.
  (Estou iniciando um novo projeto.)

- The server is starting.
  (O servidor está iniciando.)

## Frases (tempo verbal)

### Presente (1ª pessoa)

I start work at 8 a.m.

(Eu começo o trabalho às 8h.)

### Presente (3ª pessoa)

She starts meetings on time.

(Ela inicia reuniões no horário.)

### Passado

I started the application.

(Eu iniciei a aplicação.)

### Futuro

I will start the migration tomorrow.

(Eu iniciarei a migração amanhã.)

### Particípio (Present Perfect)

I have started the deployment.

(Eu iniciei a implantação.)

## Estruturas importantes

### Estrutura principal

**start + objeto**

Exemplos:

- Start the application.
  (Inicie a aplicação.)

- I started the process.
  (Eu iniciei o processo.)

- She started the meeting.
  (Ela iniciou a reunião.)

### Outras formas comuns

#### start to + verbo

- I started to learn English.
  (Comecei a aprender inglês.)

- She started to work remotely.
  (Ela começou a trabalhar remotamente.)

- We started to analyze the logs.
  (Começamos a analisar os logs.)

#### start + ING

- I started studying English.
  (Comecei a estudar inglês.)

- She started using Git.
  (Ela começou a usar Git.)

- We started testing the application.
  (Começamos a testar a aplicação.)

#### start with

- Let's start with the basics.
  (Vamos começar pelo básico.)

- We started with a small prototype.
  (Começamos com um pequeno protótipo.)

## Uso com outros verbos

### Usa -ING?

✔ Sim

Exemplos:

- I started learning Python.
  (Comecei a aprender Python.)

- She started working on the project.
  (Ela começou a trabalhar no projeto.)

- We started testing the new version.
  (Começamos a testar a nova versão.)

### Usa TO + infinitivo?

✔ Sim

Exemplos:

- I started to learn English.
  (Comecei a aprender inglês.)

- She started to review the document.
  (Ela começou a revisar o documento.)

- We started to fix the issue.
  (Começamos a corrigir o problema.)

### Preposição obrigatória?

Não possui.

Mas são comuns:

- start with
- start on

Exemplos:

- Start with the documentation.
  (Comece pela documentação.)

- We started on the new feature.
  (Começamos a trabalhar no novo recurso.)

## Frases extras (uso real)

- The application starts automatically after login.
  (A aplicação inicia automaticamente após o login.)

- We started the deployment at midnight.
  (Iniciamos a implantação à meia-noite.)

- The team started working on the issue immediately.
  (A equipe começou a trabalhar no problema imediatamente.)

- Developers should start with the documentation.
  (Desenvolvedores devem começar pela documentação.)

- The server started successfully after the update.
  (O servidor iniciou com sucesso após a atualização.)

## Erros comuns

❌ I have start the application.

✔ I have started the application.

No Present Perfect, utiliza-se **started**.

---

❌ She start work at 8 a.m.

✔ She starts work at 8 a.m.

Na 3ª pessoa do singular, adiciona-se **-s**.

---

❌ I started to studying English.

✔ I started studying English.

✔ I started to study English.

Após **start**, use **-ING** ou **to + verbo**, mas não os dois juntos.

## Observações importantes

- **Start** aceita tanto **to + infinitivo** quanto **-ING**, geralmente sem diferença de significado.
- Em TI, é extremamente comum em expressões como **start a service**, **start a deployment**, **start a process** e **start testing**.
- A expressão **start from scratch** significa "começar do zero".
