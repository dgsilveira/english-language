## Verbo: CHECK OUT

### Traduções principais
- verificar
- conferir

### Informações gerais

**Outras traduções**
- dar uma olhada
- examinar
- fazer check-out
- sair de um hotel

#### Palavras da mesma família

- check → verificar
- checkout → checkout / finalização de compra
- checked out → verificado / liberado
- checking out → verificando

#### CEFR
- B1

#### Relevância para TI
- Muito usado

#### Tipo de verbo
- Phrasal Verb

### Pronúncia (IPA – General American)

- Presente: **check out** → /tʃek aʊt/
- Presente (3ª pessoa): **checks out** → /tʃeks aʊt/
- Passado: **checked out** → /tʃekt aʊt/
- Particípio: **checked out** → /tʃekt aʊt/
- Forma em **-ING**: **checking out** → /ˈtʃekɪŋ aʊt/

### Phrasal verbs

O próprio verbo estudado já é um phrasal verb.

Outros relacionados:

- check in
- check up on
- check back
- check off

### Forma em -ING

**check out → checking out**

O verbo apenas recebe **-ING**.

- check → checking
- check out → checking out

Pronúncia:

- checking out → /ˈtʃekɪŋ aʊt/

Exemplos:

- I am checking out the new feature.
  (Estou verificando o novo recurso.)

- We are checking out the documentation.
  (Estamos analisando a documentação.)

## Frases (tempo verbal)

### Presente (1ª pessoa)

I check out new tools regularly.

(Eu verifico novas ferramentas regularmente.)

### Presente (3ª pessoa)

She checks out the reports every day.

(Ela verifica os relatórios todos os dias.)

### Passado

I checked out the new application.

(Eu analisei a nova aplicação.)

### Futuro

I will check out the update later.

(Eu vou verificar a atualização mais tarde.)

### Particípio (Present Perfect)

I have checked out the documentation.

(Eu verifiquei a documentação.)

## Estruturas importantes

### Estrutura principal

**check out + objeto**

Exemplos:

- Check out this website.
  (Dê uma olhada neste site.)

- I checked out the logs.
  (Eu analisei os logs.)

- She checked out the new feature.
  (Ela verificou o novo recurso.)

### Outras formas comuns

#### check out + recurso/produto

Muito comum para explorar algo novo.

- Check out this tool.
  (Confira esta ferramenta.)

- We checked out a new framework.
  (Analisamos um novo framework.)

- She checked out the latest version.
  (Ela verificou a versão mais recente.)

#### check out of + lugar

Usado para fazer check-out.

- I checked out of the hotel.
  (Eu fiz check-out do hotel.)

- They checked out at noon.
  (Eles fizeram check-out ao meio-dia.)

- She checked out earlier than expected.
  (Ela fez check-out mais cedo do que o esperado.)

#### something checks out

Usado para indicar que algo está correto ou faz sentido.

- The information checks out.
  (A informação está correta.)

- Everything checks out.
  (Está tudo certo.)

- The data checked out.
  (Os dados estavam corretos.)

## Uso com outros verbos

### Usa -ING?

- ✔ Sim

Exemplos:

- I enjoyed checking out the new platform.
  (Gostei de explorar a nova plataforma.)

- They spent the afternoon checking out alternatives.
  (Passaram a tarde analisando alternativas.)

- We are checking out the logs.
  (Estamos verificando os logs.)

### Usa TO + infinitivo?

- ✔ Sim

Usado para indicar finalidade.

Exemplos:

- I logged in to check out the feature.
  (Entrei para verificar o recurso.)

- She visited the website to check out the documentation.
  (Ela visitou o site para conferir a documentação.)

- We opened the report to check out the results.
  (Abrimos o relatório para verificar os resultados.)

### Preposição obrigatória?

Não possui preposição obrigatória.

As combinações mais comuns são:

- check out
- check out of

Exemplos:

- Check out this repository.
  (Confira este repositório.)

- We checked out the new dashboard.
  (Analisamos o novo painel.)

- They checked out of the hotel.
  (Eles fizeram check-out do hotel.)

## Frases extras (uso real)

- Check out the latest API documentation.
  (Confira a documentação mais recente da API.)

- I checked out the error logs this morning.
  (Analisei os logs de erro esta manhã.)

- The team checked out several solutions.
  (A equipe analisou várias soluções.)

- Everything checked out after the deployment.
  (Tudo estava correto após a implantação.)

- Developers should check out the official documentation.
  (Desenvolvedores deveriam conferir a documentação oficial.)

## Combinações mais comuns (Collocations)

### check out a website

- Check out this website for more information.
  (Confira este site para mais informações.)

### check out the documentation

- New developers should check out the documentation.
  (Novos desenvolvedores deveriam conferir a documentação.)

### check out a tool

- We checked out a new monitoring tool.
  (Analisamos uma nova ferramenta de monitoramento.)

### check out the logs

- The administrator checked out the logs.
  (O administrador analisou os logs.)

### check out the latest version

- I checked out the latest version yesterday.
  (Eu conferi a versão mais recente ontem.)

## Expressões comuns

- check it out
- check out this website
- check out the documentation
- everything checks out
- check out of a hotel

## Erros comuns

❌ Check out about this tool.

✔ Check out this tool.

Após **check out**, normalmente não se usa **about**.

---

❌ I checked out in the hotel.

✔ I checked out of the hotel.

Para sair de um hotel, utiliza-se **check out of**.

---

❌ The information is checking out.

✔ The information checks out.

Nesse sentido, o phrasal verb normalmente é usado no Simple Present.

## Observações importantes

- **Check out** frequentemente significa analisar, conferir ou dar uma olhada em algo.
- A expressão **check it out** é extremamente comum no inglês informal.
- Em TI, é muito usada para incentivar alguém a explorar uma ferramenta, documentação, biblioteca ou solução nova.
