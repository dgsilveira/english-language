## Verbo: CLEAN

### Traduções principais
- limpar
- limpar completamente

### Informações gerais

**Outras traduções**
- higienizar
- remover sujeira
- apagar
- remover arquivos desnecessários

#### Palavras da mesma família

- clean → limpo
- cleaner → limpador
- cleaning → limpeza
- cleanup (clean-up) → limpeza
- cleanly → de forma limpa

#### CEFR
- A1

#### Relevância para TI
- Muito usado

#### Tipo de verbo
- Regular

### Pronúncia (IPA – General American)

- Presente: **clean** → /kliːn/
- Presente (3ª pessoa): **cleans** → /kliːnz/
- Passado: **cleaned** → /kliːnd/
- Particípio: **cleaned** → /kliːnd/
- Forma em **-ING**: **cleaning** → /ˈkliːnɪŋ/

### Phrasal verbs

- clean up
- clean out
- clean off
- clean out of

### Forma em -ING

**clean → cleaning**

O verbo apenas recebe **-ING**.

- clean → cleaning

Pronúncia:

- cleaning → /ˈkliːnɪŋ/

Exemplos:

- I am cleaning my desk.
  (Estou limpando minha mesa.)

- We are cleaning old files.
  (Estamos limpando arquivos antigos.)

## Frases (tempo verbal)

### Presente (1ª pessoa)

I clean my workspace every day.

(Eu limpo meu espaço de trabalho todos os dias.)

### Presente (3ª pessoa)

She cleans the office regularly.

(Ela limpa o escritório regularmente.)

### Passado

I cleaned the database yesterday.

(Eu limpei o banco de dados ontem.)

### Futuro

I will clean the server logs.

(Eu limparei os logs do servidor.)

### Particípio (Present Perfect)

I have cleaned all temporary files.

(Eu limpei todos os arquivos temporários.)

## Estruturas importantes

### Estrutura principal

**clean + objeto**

Exemplos:

- Clean the room.
  (Limpe o quarto.)

- I cleaned the database.
  (Eu limpei o banco de dados.)

- She cleaned the keyboard.
  (Ela limpou o teclado.)

### Outras formas comuns

#### clean + objeto + before/after + ação

- Clean the equipment before use.
  (Limpe o equipamento antes do uso.)

- We cleaned the database after the migration.
  (Limpamos o banco de dados após a migração.)

- She cleaned the workspace before the meeting.
  (Ela limpou o espaço de trabalho antes da reunião.)

#### clean + dados/arquivos

Muito comum em TI.

- Clean old records.
  (Remova registros antigos.)

- We cleaned unnecessary files.
  (Removemos arquivos desnecessários.)

- The script cleans temporary data.
  (O script remove dados temporários.)

#### clean + área/superfície

- Clean the screen.
  (Limpe a tela.)

- Clean the desk.
  (Limpe a mesa.)

- Clean the equipment.
  (Limpe os equipamentos.)

## Uso com outros verbos

### Usa -ING?

- ✔ Sim

Exemplos:

- I spent the afternoon cleaning files.
  (Passei a tarde limpando arquivos.)

- She enjoys cleaning and organizing.
  (Ela gosta de limpar e organizar.)

- We are cleaning old data.
  (Estamos limpando dados antigos.)

### Usa TO + infinitivo?

- ✔ Sim

Exemplos:

- I need to clean the workspace.
  (Preciso limpar o espaço de trabalho.)

- We want to clean the database.
  (Queremos limpar o banco de dados.)

- She plans to clean the server room.
  (Ela planeja limpar a sala dos servidores.)

### Preposição obrigatória?

Não possui preposição obrigatória.

## Erros comuns

❌ I have clean the database.

✔ I have cleaned the database.

No Present Perfect, utiliza-se o particípio **cleaned**.

---

❌ The script clean temporary files.

✔ The script cleans temporary files.

Na 3ª pessoa do singular, adiciona-se **-s**.

---

❌ We cleaned up of old files.

✔ We cleaned up old files.

**Clean up** normalmente não exige **of** nessa estrutura.

## Observações importantes

- Em TI, **clean** é frequentemente usado para remover arquivos, registros, logs e dados desnecessários.
- O phrasal verb **clean up** é extremamente comum em programação e administração de sistemas.
- Expressões como **clean the database**, **clean the logs** e **clean temporary files** aparecem frequentemente em documentação técnica.
