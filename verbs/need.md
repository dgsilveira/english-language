## Verbo: NEED

### Traduções principais
- precisar
- necessitar

### Informações gerais

**Outras traduções**
- requerer
- demandar
- ter necessidade de
- ser necessário

#### Palavras da mesma família

- need → necessidade
- needed → necessário / precisado
- needing → precisando
- needy → necessitado
- needless → desnecessário

#### CEFR
- A1

#### Relevância para TI
- Extremamente usado

#### Tipo de verbo
- Regular

### Pronúncia (IPA – General American)

- Presente: **need** → /niːd/
- Presente (3ª pessoa): **needs** → /niːdz/
- Passado: **needed** → /ˈniːdɪd/
- Particípio: **needed** → /ˈniːdɪd/
- Forma em **-ING**: **needing** → /ˈniːdɪŋ/

### Phrasal verbs

Não existem phrasal verbs importantes derivados diretamente de **need**.

### Forma em -ING

**need → needing**

O verbo apenas recebe **-ING**.

- need → needing

Pronúncia:

- needing → /ˈniːdɪŋ/

Exemplos:

- I am needing help. *(gramaticalmente possível, mas pouco comum)*
  (Estou precisando de ajuda.)

> Normalmente usa-se o **Simple Present**:
>
> - I need help.
>   (Eu preciso de ajuda.)

---

## Frases (tempo verbal)

### Presente (1ª pessoa)

I need more information.

(Eu preciso de mais informações.)

### Presente (3ª pessoa)

She needs support.

(Ela precisa de suporte.)

### Passado

I needed more time.

(Eu precisei de mais tempo.)

### Futuro

I will need additional resources.

(Eu precisarei de recursos adicionais.)

### Particípio (Present Perfect)

I have needed this tool for a long time.

(Eu preciso desta ferramenta há muito tempo.)

---

## Estruturas importantes

### Estrutura principal

**need + objeto**

Exemplos:

- I need help.
  (Eu preciso de ajuda.)

- We need documentation.
  (Precisamos de documentação.)

- She needs training.
  (Ela precisa de treinamento.)

### Outras formas comuns

#### need to + infinitivo

Estrutura mais importante.

- I need to study.
  (Preciso estudar.)

- We need to deploy the application.
  (Precisamos implantar a aplicação.)

- She needs to update the server.
  (Ela precisa atualizar o servidor.)

#### need something for something

- We need more memory for the application.
  (Precisamos de mais memória para a aplicação.)

- I need a charger for my laptop.
  (Preciso de um carregador para meu notebook.)

#### need help with

- I need help with this issue.
  (Preciso de ajuda com este problema.)

- She needs help with configuration.
  (Ela precisa de ajuda com a configuração.)

---

## Uso com outros verbos

### Usa -ING?

- ✔ Em casos específicos

Exemplos:

- The server needs restarting.
  (O servidor precisa ser reiniciado.)

- The application needs updating.
  (A aplicação precisa ser atualizada.)

> Mais comum no inglês britânico.

### Usa TO + infinitivo?

- ✔ Sim

Esta é a estrutura mais comum.

Exemplos:

- I need to finish the report.
  (Preciso terminar o relatório.)

- We need to fix the bug.
  (Precisamos corrigir o bug.)

- She needs to learn Python.
  (Ela precisa aprender Python.)

---

## Preposição obrigatória?

Não possui preposição obrigatória.

Mas aparecem frequentemente:

- need for
- need help with

Exemplos:

- There is a need for improvement.
  (Há necessidade de melhoria.)

- I need help with deployment.
  (Preciso de ajuda com a implantação.)

---

## Frases extras (uso real)

- We need to investigate the issue.
  (Precisamos investigar o problema.)

- The application needs a security update.
  (A aplicação precisa de uma atualização de segurança.)

- Developers need access to the repository.
  (Desenvolvedores precisam de acesso ao repositório.)

- The team needs more time to complete the project.
  (A equipe precisa de mais tempo para concluir o projeto.)

- We need to review the logs before deployment.
  (Precisamos revisar os logs antes da implantação.)

---

## Erros comuns

❌ She need help.

✔ She needs help.

Na 3ª pessoa do singular, adiciona-se **-s**.

---

❌ I need finish the report.

✔ I need to finish the report.

Após **need**, normalmente utiliza-se **to + infinitive**.

---

❌ I have need this tool.

✔ I have needed this tool.

No Present Perfect, utiliza-se o particípio **needed**.

---

## Observações importantes

- A estrutura mais importante é:

**need to + verbo**

Exemplos:

- I need to learn English.
- We need to deploy the update.
- She needs to solve the issue.

- Em TI, **need** aparece constantemente em frases como:
  - **need access**
  - **need support**
  - **need more resources**
  - **need to deploy**
  - **need to troubleshoot**

- É um dos verbos mais frequentes no inglês profissional e técnico.
