# Verbo: THROW

## Traduções principais
- jogar
- arremessar

### Informações gerais

**Outras traduções**
- lançar
- atirar
- descartar
- disparar (em alguns contextos)

#### Palavras da mesma família

- throw → arremesso
- thrown → lançado
- throwing → arremessando
- thrower → arremessador

#### CEFR
- A2

#### Relevância para TI
- Usado

#### Tipo de verbo

- Irregular

### Pronúncia (IPA – General American)

- Presente: **throw** → /θroʊ/
- Presente (3ª pessoa): **throws** → /θroʊz/
- Passado: **threw** → /θruː/
- Particípio: **thrown** → /θroʊn/
- Forma em **-ING**: **throwing** → /ˈθroʊɪŋ/

### Phrasal verbs

- throw away
- throw out
- throw in
- throw back

### Forma em -ING

**throw → throwing**

O verbo apenas recebe **-ING**.

Exemplos:

- I am throwing the ball.
  (Estou jogando a bola.)

- She is throwing away old documents.
  (Ela está jogando fora documentos antigos.)

## Frases (tempo verbal)

### Presente (1ª pessoa)

I throw the ball carefully.

(Eu jogo a bola com cuidado.)

### Presente (3ª pessoa)

She throws the keys on the table.

(Ela joga as chaves sobre a mesa.)

### Passado

I threw the ball yesterday.

(Eu joguei a bola ontem.)

### Futuro

I will throw it away later.

(Eu jogarei isso fora mais tarde.)

### Particípio (Present Perfect)

I have thrown away the old files.

(Eu joguei fora os arquivos antigos.)

## Estruturas importantes

### Estrutura principal

**throw + objeto**

Exemplos:

- Throw the ball.
  (Jogue a bola.)

- I threw the paper away.
  (Eu joguei o papel fora.)

- She throws the package carefully.
  (Ela lança o pacote com cuidado.)

### Outras formas comuns

#### throw away

- Throw away the trash.
  (Jogue o lixo fora.)

- I threw away old documents.
  (Eu joguei fora documentos antigos.)

- She threw away unnecessary files.
  (Ela descartou arquivos desnecessários.)

#### throw out

- We threw out the broken equipment.
  (Nós descartamos o equipamento quebrado.)

- The system threw out invalid entries.
  (O sistema descartou registros inválidos.)

#### throw an exception

- The application throws an exception.
  (A aplicação gera uma exceção.)

- The method threw an error.
  (O método gerou um erro.)

- The code throws a runtime exception.
  (O código lança uma exceção em tempo de execução.)

## Uso com outros verbos

### Usa -ING?

✔ Sim

Exemplos:

- Throwing objects is not allowed.
  (Arremessar objetos não é permitido.)

- I enjoy throwing a ball with my friends.
  (Gosto de jogar bola com meus amigos.)

- The application is throwing errors.
  (A aplicação está gerando erros.)

### Usa TO + infinitivo?

✔ Sim

Exemplos:

- I want to throw the ball.
  (Quero jogar a bola.)

- We need to throw away old files.
  (Precisamos descartar arquivos antigos.)

- She plans to throw out unused equipment.
  (Ela planeja descartar equipamentos sem uso.)

### Preposição obrigatória?

Não possui.

Mas são comuns:

- throw away
- throw out
- throw at

Exemplos:

- Throw away the trash.
  (Jogue o lixo fora.)

- Don't throw things at people.
  (Não jogue coisas nas pessoas.)

## Frases extras (uso real)

- The application threw an unexpected exception.
  (A aplicação lançou uma exceção inesperada.)

- We threw away outdated documentation.
  (Descartamos documentação desatualizada.)

- The server threw several error messages during startup.
  (O servidor gerou várias mensagens de erro durante a inicialização.)

- Developers should investigate why the code throws exceptions.
  (Os desenvolvedores devem investigar por que o código lança exceções.)

- I threw out old backup files to save disk space.
  (Descartei arquivos antigos de backup para economizar espaço em disco.)

## Combinações mais comuns (Collocations)

### throw a ball

- He threw a ball to his friend.
  (Ele jogou uma bola para o amigo.)

### throw away trash

- Please throw away the trash.
  (Por favor, jogue o lixo fora.)

### throw out old files

- We threw out old files last week.
  (Descartamos arquivos antigos na semana passada.)

### throw an exception

- The method throws an exception when validation fails.
  (O método lança uma exceção quando a validação falha.)

### throw an error

- The script threw an error during execution.
  (O script gerou um erro durante a execução.)

## Expressões comuns

- throw away
- throw out
- throw an exception
- throw an error
- throw caution to the wind

## Erros comuns

❌ I have threw the file away.

✔ I have thrown the file away.

O particípio correto é **thrown**.

---

❌ Yesterday I thrown the ball.

✔ Yesterday I threw the ball.

No passado simples, utiliza-se **threw**.

---

❌ She throw an exception.

✔ She throws an exception.

Na 3ª pessoa do singular, adiciona-se **-s**.

## Observações importantes

- As formas corretas são: **throw → threw → thrown**.
- Em TI, **throw an exception** e **throw an error** são usos extremamente comuns.
- Um erro frequente é confundir **threw** (passado) com **thrown** (particípio).
