## Verbo: PICK UP

### Traduções principais
- pegar
- buscar

### Informações gerais

**Outras traduções**
- apanhar
- recolher
- adquirir
- aprender informalmente
- atender (telefone)

#### Palavras da mesma família

- pick → pegar / escolher
- pickup → coleta / retirada
- picked up → pegou / aprendeu
- picking up → pegando
- pickup point → ponto de retirada

#### CEFR
- A2

#### Relevância para TI
- Muito usado

#### Tipo de verbo
- Phrasal Verb

### Pronúncia (IPA – General American)

- Presente: **pick up** → /pɪk ʌp/
- Presente (3ª pessoa): **picks up** → /pɪks ʌp/
- Passado: **picked up** → /pɪkt ʌp/
- Particípio: **picked up** → /pɪkt ʌp/
- Forma em **-ING**: **picking up** → /ˈpɪkɪŋ ʌp/

### Phrasal verbs

O próprio verbo estudado já é um phrasal verb.

Relacionados:

- pick up
- pick out
- pick on
- pick off

### Forma em -ING

**pick up → picking up**

Exemplos:

- I am picking up the package.
  (Estou pegando a encomenda.)

- She is picking up new skills.
  (Ela está adquirindo novas habilidades.)

## Estruturas importantes

### Estrutura principal

**pick up + objeto**

Exemplos:

- Pick up the book.
  (Pegue o livro.)

- I picked up the package.
  (Eu peguei a encomenda.)

- She picked up the phone.
  (Ela atendeu o telefone.)

### Outras formas comuns

#### pick up the phone

- Please pick up the phone.
  (Por favor, atenda o telefone.)

- Nobody picked up.
  (Ninguém atendeu.)

#### pick up skills

- I picked up some programming skills.
  (Adquiri algumas habilidades de programação.)

- She picked up English while traveling.
  (Ela aprendeu inglês durante as viagens.)

#### pick up data/signal

Muito comum em TI.

- The device picked up the signal.
  (O dispositivo captou o sinal.)

- The system picked up unusual activity.
  (O sistema detectou atividade incomum.)

## Uso com outros verbos

### Usa -ING?

- ✔ Sim

Exemplos:

- Picking up new skills is important.
  (Adquirir novas habilidades é importante.)

- I enjoy picking up new languages.
  (Eu gosto de aprender novos idiomas.)

- The sensor is picking up noise.
  (O sensor está captando ruído.)

### Usa TO + infinitivo?

- ✔ Sim

Exemplos:

- I want to pick up the package.
  (Quero pegar a encomenda.)

- We need to pick up the equipment.
  (Precisamos pegar o equipamento.)

- She plans to pick up a new certification.
  (Ela planeja obter uma nova certificação.)

### Preposição obrigatória?

✅ Sim.

A palavra **up** faz parte do phrasal verb.

Exemplos:

- Pick up the phone.
  (Atenda o telefone.)

- Pick up the package.
  (Pegue a encomenda.)

## Erros comuns

❌ I have pick up the package.

✔ I have picked up the package.

No Present Perfect, utiliza-se **picked up**.

---

❌ She pick up the phone every time.

✔ She picks up the phone every time.

Na 3ª pessoa do singular, adiciona-se **-s**.

---

❌ The system picked the signal.

✔ The system picked up the signal.

O significado correto exige o phrasal verb **pick up**.

---

## Observações importantes

- **Pick up** possui vários significados dependendo do contexto:

### 1. Pegar / recolher

- Pick up the package.
  (Pegue a encomenda.)

### 2. Atender

- Pick up the phone.
  (Atenda o telefone.)

### 3. Aprender informalmente

- Pick up a language.
  (Aprender um idioma naturalmente.)

### 4. Detectar / captar

- Pick up a signal.
  (Captar um sinal.)

- Em TI, é muito comum em expressões como:
  - **pick up a signal**
  - **pick up data**
  - **pick up an event**
  - **pick up a configuration**
  - **pick up an anomaly**
