## Verbo: DESIGN

### Traduções principais
- projetar
- desenhar

### Informações gerais

**Outras traduções**
- desenvolver
- criar
- planejar
- conceber

#### Palavras da mesma família

- design → design / projeto
- designer → designer / projetista
- designed → projetado
- designing → projetando
- redesign → redesenhar

#### CEFR
- A2

#### Relevância para TI
- Muito usado

#### Tipo de verbo
- Regular

### Pronúncia (IPA – General American)

- Presente: **design** → /dɪˈzaɪn/
- Presente (3ª pessoa): **designs** → /dɪˈzaɪnz/
- Passado: **designed** → /dɪˈzaɪnd/
- Particípio: **designed** → /dɪˈzaɪnd/
- Forma em **-ING**: **designing** → /dɪˈzaɪnɪŋ/

### Phrasal verbs

Não existem phrasal verbs muito relevantes derivados diretamente de **design**.

### Forma em -ING

**design → designing**

O verbo apenas recebe **-ING**.

- design → designing

Pronúncia:

- designing → /dɪˈzaɪnɪŋ/

Exemplos:

- I am designing a new system.
  (Estou projetando um novo sistema.)

- She is designing a user interface.
  (Ela está projetando uma interface de usuário.)

## Frases (tempo verbal)

### Presente (1ª pessoa)

I design web applications.

(Eu projeto aplicações web.)

### Presente (3ª pessoa)

She designs modern interfaces.

(Ela projeta interfaces modernas.)

### Passado

I designed a new database.

(Eu projetei um novo banco de dados.)

### Futuro

I will design a better solution.

(Eu projetarei uma solução melhor.)

### Particípio (Present Perfect)

I have designed several systems.

(Eu projetei vários sistemas.)

## Estruturas importantes

### Estrutura principal

**design + objeto**

Exemplos:

- Design a website.
  (Projete um site.)

- I designed a dashboard.
  (Eu projetei um painel.)

- She designed a mobile application.
  (Ela projetou uma aplicação móvel.)

### Outras formas comuns

#### design + objeto + for + pessoa

Usado para indicar o destinatário.

- We designed a solution for the client.
  (Projetamos uma solução para o cliente.)

- She designed a tool for developers.
  (Ela projetou uma ferramenta para desenvolvedores.)

- I designed a report for managers.
  (Eu projetei um relatório para gestores.)

#### design + objeto + to + infinitivo

Usado para indicar finalidade.

- This system was designed to scale.
  (Este sistema foi projetado para escalar.)

- The feature was designed to improve performance.
  (O recurso foi projetado para melhorar o desempenho.)

- The API was designed to handle large volumes.
  (A API foi projetada para lidar com grandes volumes.)

#### design + with + característica

- We designed the application with security in mind.
  (Projetamos a aplicação pensando em segurança.)

- She designed the interface with accessibility in mind.
  (Ela projetou a interface pensando em acessibilidade.)

- The platform was designed with flexibility in mind.
  (A plataforma foi projetada pensando em flexibilidade.)

## Uso com outros verbos

### Usa -ING?

- ✔ Sim

Exemplos:

- I enjoy designing systems.
  (Eu gosto de projetar sistemas.)

- Designing APIs requires planning.
  (Projetar APIs exige planejamento.)

- She is interested in designing user interfaces.
  (Ela tem interesse em projetar interfaces de usuário.)

### Usa TO + infinitivo?

- ✔ Sim

Exemplos:

- I want to design a new application.
  (Eu quero projetar uma nova aplicação.)

- We need to design a scalable solution.
  (Precisamos projetar uma solução escalável.)

- She plans to design a new workflow.
  (Ela planeja projetar um novo fluxo de trabalho.)

### Preposição obrigatória?

Não possui preposição obrigatória.

As combinações mais comuns são:

- design for
- design with
- design to

Exemplos:

- We designed the product for beginners.
  (Projetamos o produto para iniciantes.)

- The solution was designed with security in mind.
  (A solução foi projetada pensando em segurança.)

- The system was designed to support growth.
  (O sistema foi projetado para suportar crescimento.)

## Erros comuns

❌ I have design a new system.

✔ I have designed a new system.

No Present Perfect, utiliza-se o particípio **designed**.

---

❌ The application was designed for be secure.

✔ The application was designed to be secure.

Após **designed**, usa-se normalmente **to + infinitive**.

---

❌ We designed a solution to the client.

✔ We designed a solution for the client.

A preposição correta é **for**.

## Observações importantes

- **Design** é um dos verbos mais importantes em arquitetura de software, UX/UI e engenharia de sistemas.
- A estrutura **be designed to + infinitive** é extremamente comum em documentação técnica.
- Expressões como **design a system**, **design a database** e **design a solution** aparecem frequentemente em ambientes de TI.
