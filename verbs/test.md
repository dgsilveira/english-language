# Verbo: TEST

## Traduções principais
- testar

### Informações gerais

**Outras traduções**
- verificar
- avaliar
- examinar
- colocar à prova

#### Palavras da mesma família

- test → teste
- tested → testado
- testing → teste / testando
- tester → testador
- test case → caso de teste

#### CEFR
- A2

#### Relevância para TI
- Extremamente usado

#### Tipo de verbo

- Regular

### Pronúncia (IPA – General American)

- Presente: **test** → /test/
- Presente (3ª pessoa): **tests** → /tests/
- Passado: **tested** → /ˈtestɪd/
- Particípio: **tested** → /ˈtestɪd/
- Forma em **-ING**: **testing** → /ˈtestɪŋ/

### Phrasal verbs

Não existem phrasal verbs realmente relevantes para **test**.

### Forma em -ING

**test → testing**

O verbo apenas recebe **-ING**.

Exemplos:

- I am testing the application.
  (Estou testando a aplicação.)

- She is testing a new feature.
  (Ela está testando um novo recurso.)

## Frases (tempo verbal)

### Presente (1ª pessoa)

I test software regularly.

(Eu testo software regularmente.)

### Presente (3ª pessoa)

She tests new features before release.

(Ela testa novos recursos antes da liberação.)

### Passado

I tested the application yesterday.

(Eu testei a aplicação ontem.)

### Futuro

I will test the new version tomorrow.

(Eu testarei a nova versão amanhã.)

### Particípio (Present Perfect)

I have tested this feature before.

(Eu já testei este recurso antes.)

## Estruturas importantes

### Estrutura principal

**test + objeto**

Exemplos:

- Test the application.
  (Teste a aplicação.)

- I tested the API.
  (Eu testei a API.)

- She tested the system.
  (Ela testou o sistema.)

### Outras formas comuns

#### test a feature

- We tested the new feature.
  (Nós testamos o novo recurso.)

- She tested the login function.
  (Ela testou a função de login.)

- The team tested the update.
  (A equipe testou a atualização.)

#### test a system

- Developers tested the system thoroughly.
  (Os desenvolvedores testaram o sistema cuidadosamente.)

- We tested the production environment.
  (Testamos o ambiente de produção.)

#### test for

- The script tests for errors.
  (O script verifica a existência de erros.)

- The application tests for security vulnerabilities.
  (A aplicação verifica vulnerabilidades de segurança.)

## Uso com outros verbos

### Usa -ING?

✔ Sim

Exemplos:

- Testing is an essential part of development.
  (Testar é uma parte essencial do desenvolvimento.)

- I enjoy testing new tools.
  (Gosto de testar novas ferramentas.)

- They are testing the deployment process.
  (Eles estão testando o processo de implantação.)

### Usa TO + infinitivo?

✔ Sim

Exemplos:

- I want to test the new feature.
  (Quero testar o novo recurso.)

- We need to test the application.
  (Precisamos testar a aplicação.)

- She plans to test the API tomorrow.
  (Ela planeja testar a API amanhã.)

### Preposição obrigatória?

Não possui.

Mas é comum:

- **test for**

Exemplos:

- Test for bugs.
  (Verifique a existência de bugs.)

- Test for vulnerabilities.
  (Verifique a existência de vulnerabilidades.)

## Frases extras (uso real)

- The team tested the deployment in a staging environment.
  (A equipe testou a implantação em um ambiente de homologação.)

- We need to test the backup process regularly.
  (Precisamos testar o processo de backup regularmente.)

- The developer tested the API before publishing it.
  (O desenvolvedor testou a API antes de publicá-la.)

- Automated tests help detect issues early.
  (Testes automatizados ajudam a detectar problemas cedo.)

- The application was tested on multiple devices.
  (A aplicação foi testada em vários dispositivos.)

## Combinações mais comuns (Collocations)

### test a feature

- We tested the feature before release.
  (Testamos o recurso antes da liberação.)

### test an application

- The QA team tested the application.
  (A equipe de QA testou a aplicação.)

### test a system

- Engineers tested the system thoroughly.
  (Os engenheiros testaram o sistema cuidadosamente.)

### test for bugs

- Always test for bugs before deployment.
  (Sempre verifique a existência de bugs antes da implantação.)

### test a solution

- We tested the solution in production.
  (Testamos a solução em produção.)

## Expressões comuns

- test a feature
- test a system
- test for bugs
- beta test
- test environment

## Erros comuns

❌ I have test the application.

✔ I have tested the application.

No Present Perfect, utiliza-se **tested**.

---

❌ She test new features every week.

✔ She tests new features every week.

Na 3ª pessoa do singular, adiciona-se **-s**.

---

❌ We tested for the application.

✔ We tested the application.

**Test** normalmente recebe o objeto diretamente.

## Observações importantes

- Em TI, **test** é um dos verbos mais utilizados em desenvolvimento de software.
- A expressão **test for** significa verificar a existência de algo, como erros ou vulnerabilidades.
- É comum encontrar expressões como **test a feature**, **test a system**, **automated testing** e **beta testing**.
