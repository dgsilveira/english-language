## Verbo: PASS

### Traduções principais
- passar

### Informações gerais

**Outras traduções**
- atravessar
- entregar
- transmitir
- ser aprovado

#### Palavras da mesma família

- pass → passagem
- passed → passado / aprovado
- passing → passando
- passerby → transeunte
- passport → passaporte

#### CEFR
- A1

#### Relevância para TI
- Muito usado

#### Tipo de verbo
- Regular

### Pronúncia (IPA – General American)

- Presente: **pass** → /pæs/
- Presente (3ª pessoa): **passes** → /ˈpæsɪz/
- Passado: **passed** → /pæst/
- Particípio: **passed** → /pæst/
- Forma em **-ING**: **passing** → /ˈpæsɪŋ/

### Phrasal verbs

- pass on
- pass by
- pass out
- pass through
- pass away

### Forma em -ING

**pass → passing**

O verbo apenas recebe **-ING**.

- pass → passing

Pronúncia:

- passing → /ˈpæsɪŋ/

Exemplos:

- I am passing the information to the team.
  (Estou passando a informação para a equipe.)

- Data is passing through the network.
  (Os dados estão passando pela rede.)

## Frases (tempo verbal)

### Presente (1ª pessoa)

I pass information to my team.

(Eu passo informações para minha equipe.)

### Presente (3ª pessoa)

She passes all the tests.

(Ela passa em todos os testes.)

### Passado

I passed the certification exam.

(Eu passei no exame de certificação.)

### Futuro

I will pass the report to the manager.

(Eu passarei o relatório para o gerente.)

### Particípio (Present Perfect)

I have passed several technical exams.

(Eu passei em vários exames técnicos.)

## Estruturas importantes

### Estrutura principal

**pass + objeto**

Exemplos:

- Pass the ball.
  (Passe a bola.)

- Pass the file.
  (Passe o arquivo.)

- Pass the information.
  (Passe a informação.)

### Outras formas comuns

#### pass an exam

- I passed the exam.
  (Eu passei no exame.)

- She passed the certification.
  (Ela passou na certificação.)

#### pass information

- We passed the details to the team.
  (Passamos os detalhes para a equipe.)

- The system passes data between services.
  (O sistema transmite dados entre serviços.)

#### pass through

Muito comum em TI.

- Traffic passes through the firewall.
  (O tráfego passa pelo firewall.)

- Data passes through several layers.
  (Os dados passam por várias camadas.)

## Uso com outros verbos

### Usa -ING?

- ✔ Sim

Exemplos:

- Passing data securely is important.
  (Transmitir dados com segurança é importante.)

- I enjoy passing knowledge to others.
  (Eu gosto de transmitir conhecimento aos outros.)

- Information is passing through the system.
  (As informações estão passando pelo sistema.)

### Usa TO + infinitivo?

- ✔ Sim

Exemplos:

- I want to pass the certification exam.
  (Quero passar no exame de certificação.)

- We need to pass the results to management.
  (Precisamos passar os resultados para a gerência.)

- She plans to pass the information along.
  (Ela planeja repassar a informação.)

### Preposição obrigatória?

Não possui preposição obrigatória.

Mas combinações comuns incluem:

- pass to
- pass through
- pass on

Exemplos:

- Pass the message to John.
  (Passe a mensagem para John.)

- Data passes through the network.
  (Os dados passam pela rede.)

## Erros comuns

❌ I have pass the exam.

✔ I have passed the exam.

No Present Perfect, utiliza-se **passed**.

---

❌ She pass all tests.

✔ She passes all tests.

Na 3ª pessoa do singular, adiciona-se **-es**.

---

❌ Data passes in the firewall.

✔ Data passes through the firewall.

A expressão correta é **pass through**.

---

## Observações importantes

- **Pass** possui vários significados:
  - passar em uma prova (*pass an exam*)
  - transmitir algo (*pass information*)
  - atravessar um local (*pass through*)
  - entregar algo a alguém (*pass the file*)

- Em TI, é muito comum em expressões como:
  - **pass data**
  - **pass parameters**
  - **pass a test**
  - **pass security checks**
  - **pass through a firewall**

- Não confunda:
  - **pass** = passar
  - **past** = passado
