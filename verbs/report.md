# Verbo: REPORT

## Traduções principais
- relatar
- informar

---

## Informações gerais

### Outras traduções

- comunicar
- reportar
- registrar
- denunciar

### Palavras da mesma família

- report → relatório
- reporter → repórter
- reported → relatado
- reporting → relatando
- reportable → reportável

### CEFR

- B1

### Relevância para TI

- Extremamente usado

### Tipo de verbo

- Regular

---

## Pronúncia (IPA – General American)

- Presente: **report** → /rɪˈpɔːrt/
- Presente (3ª pessoa): **reports** → /rɪˈpɔːrts/
- Passado: **reported** → /rɪˈpɔːrtɪd/
- Particípio: **reported** → /rɪˈpɔːrtɪd/
- Forma em **-ING**: **reporting** → /rɪˈpɔːrtɪŋ/

---

## Forma em -ING

**report → reporting**

Exemplos:

- I am reporting a problem.
  (Estou relatando um problema.)

- Users are reporting errors.
  (Os usuários estão relatando erros.)

---

## Frases (tempo verbal)

### Presente (1ª pessoa)

I report issues immediately.

(Eu relato problemas imediatamente.)

### Presente (3ª pessoa)

She reports bugs regularly.

(Ela relata bugs regularmente.)

### Passado

I reported the incident yesterday.

(Eu relatei o incidente ontem.)

### Futuro

I will report the results tomorrow.

(Eu relatarei os resultados amanhã.)

### Particípio (Present Perfect)

I have reported the issue.

(Eu relatei o problema.)

---

## Estruturas importantes

### Estrutura principal

**report + objeto**

Exemplos:

- Report a problem.
  (Relate um problema.)

- Report an incident.
  (Relate um incidente.)

- Report a bug.
  (Relate um bug.)

### Report that + oração

- The team reported that the issue was fixed.
  (A equipe informou que o problema foi corrigido.)

- Users reported that the system was slow.
  (Os usuários relataram que o sistema estava lento.)

### Report to

- Employees report to a manager.
  (Funcionários respondem a um gerente.)

- She reports to the IT director.
  (Ela responde ao diretor de TI.)

---

## Uso com outros verbos

### Usa -ING?

✅ Sim.

Exemplos:

- Reporting bugs helps improve software quality.
  (Relatar bugs ajuda a melhorar a qualidade do software.)

- Users keep reporting the same issue.
  (Os usuários continuam relatando o mesmo problema.)

- Engineers are reporting performance improvements.
  (Os engenheiros estão relatando melhorias de desempenho.)

### Usa TO + infinitivo?

✅ Sim.

Exemplos:

- I need to report this problem.
  (Preciso relatar este problema.)

- We want to report the findings.
  (Queremos relatar as descobertas.)

- She plans to report the results next week.
  (Ela planeja relatar os resultados na próxima semana.)

---

## Preposição obrigatória?

Não possui.

Mas são comuns:

- report to
- report on

Exemplos:

- Report to your manager.
  (Reporte-se ao seu gerente.)

- Report on project status.
  (Relatar o status do projeto.)

---

## Frases extras (uso real)

- Users reported a login issue.
  (Os usuários relataram um problema de login.)

- The application reported an unexpected error.
  (A aplicação relatou um erro inesperado.)

  (Os engenheiros relataram melhor desempenho após a atualização.)

  (Relatamos a indisponibilidade à gerência.)

  (O sistema de monitoramento relatou atividade incomum.)

## Erros comuns

❌ I have report the issue.

✔ I have reported the issue.

No Present Perfect, utiliza-se **reported**.

---

❌ She report bugs every day.

✔ She reports bugs every day.

Na 3ª pessoa do singular, adiciona-se **-s**.

---

❌ Users reported about the problem.

✔ Users reported the problem.

Normalmente **report** recebe o objeto diretamente.

---

## Observações importantes

- **Report** pode significar:

  1. Relatar ou informar algo.
  2. Registrar uma ocorrência.
  3. Responder hierarquicamente a alguém (*report to*).

### Em TI é muito comum em:

- report a bug
- report an issue
- report an incident
- report system status
- report results

### Frase clássica

**Please report any issues immediately.**

➡️ **Por favor, relate qualquer problema imediatamente.**
