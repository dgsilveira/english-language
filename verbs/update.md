# Verbo: UPDATE

## Traduções principais
- atualizar
- modificar

### Informações gerais

**Outras traduções**
- corrigir
- revisar informações
- manter atualizado
- fazer uma nova versão

#### Palavras da mesma família

- update → atualização
- updated → atualizado
- updating → atualizando
- updater → atualizador

#### CEFR
- A2

#### Relevância para TI
- Extremamente usado

#### Tipo de verbo

- Regular

### Pronúncia (IPA – General American)

- Presente: **update** → /ˌʌpˈdeɪt/
- Presente (3ª pessoa): **updates** → /ˌʌpˈdeɪts/
- Passado: **updated** → /ˌʌpˈdeɪtɪd/
- Particípio: **updated** → /ˌʌpˈdeɪtɪd/
- Forma em **-ING**: **updating** → /ˌʌpˈdeɪtɪŋ/

### Phrasal verbs

Não existem phrasal verbs realmente relevantes para **update**.

### Forma em -ING

**update → updating**

O verbo perde o **e** final antes de adicionar **-ING**.

Exemplos:

- I am updating the application.
  (Estou atualizando a aplicação.)

- She is updating the documentation.
  (Ela está atualizando a documentação.)

## Frases (tempo verbal)

### Presente (1ª pessoa)

I update the system regularly.

(Eu atualizo o sistema regularmente.)

### Presente (3ª pessoa)

She updates the database every week.

(Ela atualiza o banco de dados toda semana.)

### Passado

I updated the application yesterday.

(Eu atualizei a aplicação ontem.)

### Futuro

I will update the report tomorrow.

(Eu atualizarei o relatório amanhã.)

### Particípio (Present Perfect)

I have updated the documentation.

(Eu atualizei a documentação.)

## Estruturas importantes

### Estrutura principal

**update + objeto**

Exemplos:

- Update the system.
  (Atualize o sistema.)

- I updated the file.
  (Eu atualizei o arquivo.)

- She updated the records.
  (Ela atualizou os registros.)

### Outras formas comuns

#### update a system

- We updated the production system.
  (Atualizamos o sistema de produção.)

- The administrator updated the server.
  (O administrador atualizou o servidor.)

- She updated the operating system.
  (Ela atualizou o sistema operacional.)

#### update documentation

- Please update the documentation.
  (Por favor, atualize a documentação.)

- We updated the user guide.
  (Atualizamos o guia do usuário.)

#### update someone on

- I'll update you on the project status.
  (Vou atualizar você sobre o status do projeto.)

- She updated the team on the incident.
  (Ela atualizou a equipe sobre o incidente.)

- We updated management on the deployment.
  (Atualizamos a gerência sobre a implantação.)

## Uso com outros verbos

### Usa -ING?

✔ Sim

Exemplos:

- Updating software improves security.
  (Atualizar software melhora a segurança.)

- I enjoy updating documentation.
  (Gosto de atualizar documentação.)

- They are updating the server now.
  (Eles estão atualizando o servidor agora.)

### Usa TO + infinitivo?

✔ Sim

Exemplos:

- I need to update the application.
  (Preciso atualizar a aplicação.)

- We want to update the database.
  (Queremos atualizar o banco de dados.)

- She plans to update the website tomorrow.
  (Ela planeja atualizar o site amanhã.)

### Preposição obrigatória?

Não possui.

Mas é comum:

- **update someone on**

Exemplos:

- Update me on the project.
  (Atualize-me sobre o projeto.)

- She updated us on the situation.
  (Ela nos atualizou sobre a situação.)

## Frases extras (uso real)

- Developers should update dependencies regularly.
  (Desenvolvedores devem atualizar dependências regularmente.)

- We updated the API documentation after the release.
  (Atualizamos a documentação da API após a liberação.)

- The administrator updated the server during the maintenance window.
  (O administrador atualizou o servidor durante a janela de manutenção.)

- The application automatically updates user settings.
  (A aplicação atualiza automaticamente as configurações dos usuários.)

- Please update the ticket after resolving the issue.
  (Por favor, atualize o chamado após resolver o problema.)

## Combinações mais comuns (Collocations)

### update the system

- We need to update the system.
  (Precisamos atualizar o sistema.)

### update the documentation

- Please update the documentation.
  (Por favor, atualize a documentação.)

### update a database

- The script updates the database automatically.
  (O script atualiza o banco de dados automaticamente.)

### update dependencies

- Developers updated the dependencies.
  (Os desenvolvedores atualizaram as dependências.)

### update someone on something

- She updated the team on the latest changes.
  (Ela atualizou a equipe sobre as últimas alterações.)

## Expressões comuns

- update the system
- update the documentation
- update dependencies
- update a database
- update someone on something

## Erros comuns

❌ I have update the application.

✔ I have updated the application.

No Present Perfect, utiliza-se **updated**.

---

❌ She update the database every day.

✔ She updates the database every day.

Na 3ª pessoa do singular, adiciona-se **-s**.

---

❌ Please update about the issue.

✔ Please update me on the issue.

✔ Please update the ticket.

**Update** normalmente precisa de um objeto direto ou da estrutura **update someone on**.

## Observações importantes

- Em TI, **update** é um dos verbos mais utilizados em contextos de software, sistemas, bancos de dados e documentação.
- A estrutura **update someone on something** é muito comum em ambientes corporativos.
- Não confunda **update** (atualizar) com **upgrade** (fazer uma melhoria ou evolução de versão).
