# Verbo: RECOMMEND

## Traduções principais
- recomendar

---

## Informações gerais

### Outras traduções

- sugerir
- aconselhar
- indicar
- propor como boa opção

### Palavras da mesma família

- recommendation → recomendação
- recommended → recomendado
- recommending → recomendando
- recommender → recomendador

### CEFR

- B1

### Relevância para TI

- Muito usado

### Tipo de verbo

- Regular

---

## Pronúncia (IPA – General American)

- Presente: **recommend** → /ˌrekəˈmend/
- Presente (3ª pessoa): **recommends** → /ˌrekəˈmendz/
- Passado: **recommended** → /ˌrekəˈmendɪd/
- Particípio: **recommended** → /ˌrekəˈmendɪd/
- Forma em **-ING**: **recommending** → /ˌrekəˈmendɪŋ/

---

## Forma em -ING

**recommend → recommending**

Exemplos:

- I am recommending this course.
  (Estou recomendando este curso.)

- She is recommending a new solution.
  (Ela está recomendando uma nova solução.)

---

## Frases (tempo verbal)

### Presente (1ª pessoa)

I recommend this book.

(Eu recomendo este livro.)

### Presente (3ª pessoa)

She recommends Python for beginners.

(Ela recomenda Python para iniciantes.)

### Passado

I recommended a different approach.

(Eu recomendei uma abordagem diferente.)

### Futuro

I will recommend this tool to the team.

(Eu recomendarei esta ferramenta para a equipe.)

### Particípio (Present Perfect)

I have recommended this software before.

(Eu já recomendei este software antes.)

---

## Estruturas importantes

### Estrutura principal

**recommend + objeto**

Exemplos:

- I recommend this book.
  (Eu recomendo este livro.)

- We recommend the latest version.
  (Recomendamos a versão mais recente.)

- She recommends this framework.
  (Ela recomenda este framework.)

### Recommend + ING

Muito comum.

- I recommend using Docker.
  (Eu recomendo usar Docker.)

- We recommend testing before deployment.
  (Recomendamos testar antes da implantação.)

- She recommends learning Python first.
  (Ela recomenda aprender Python primeiro.)

### Recommend that + oração

- I recommend that you update the system.
  (Recomendo que você atualize o sistema.)

- We recommend that the team review the logs.
  (Recomendamos que a equipe revise os logs.)

---

## Uso com outros verbos

### Usa -ING?

✅ Sim. É muito comum.

Exemplos:

- I recommend reading this article.
  (Recomendo ler este artigo.)

- She recommends using strong passwords.
  (Ela recomenda usar senhas fortes.)

- We recommend backing up your data.
  (Recomendamos fazer backup dos seus dados.)

### Usa TO + infinitivo?

❌ Normalmente não.

❌ I recommend to use Docker.

✔ I recommend using Docker.

❌ She recommended to study Python.

✔ She recommended studying Python.

✔ She recommended that I study Python.

---

## Preposição obrigatória?

Não possui.

Mas é comum:

- recommend for
- recommend to

Exemplos:

- This course is recommended for beginners.
  (Este curso é recomendado para iniciantes.)

- I recommended the book to my friend.
  (Eu recomendei o livro ao meu amigo.)

---

## Erros comuns

❌ I recommend to use this tool.

✔ I recommend using this tool.

Após **recommend**, normalmente utiliza-se **-ING**.

---

❌ She recommend this software.

✔ She recommends this software.

Na 3ª pessoa do singular, adiciona-se **-s**.

---

❌ I have recommend this course.

✔ I have recommended this course.

No Present Perfect, utiliza-se **recommended**.

---

## Observações importantes

- A estrutura mais comum é:

**recommend + ING**

Exemplos:

- recommend using
- recommend reading
- recommend learning
- recommend testing

- Não confunda:

  - **recommend** = recomendar
  - **suggest** = sugerir
  - **advise** = aconselhar

### Frase clássica

**I highly recommend reading the documentation.**

➡️ **Eu recomendo fortemente ler a documentação.**
