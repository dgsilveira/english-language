## Verbo: DESCRIBE

### Traduções principais
- descrever

### Informações gerais

**Outras traduções**
- explicar
- retratar
- detalhar
- caracterizar

#### Palavras da mesma família

- description → descrição
- descriptive → descritivo
- described → descrito
- describing → descrevendo
- descriptor → descritor

#### CEFR
- A2

#### Relevância para TI
- Muito usado

#### Tipo de verbo
- Regular

### Pronúncia (IPA – General American)

- Presente: **describe** → /dɪˈskraɪb/
- Presente (3ª pessoa): **describes** → /dɪˈskraɪbz/
- Passado: **described** → /dɪˈskraɪbd/
- Particípio: **described** → /dɪˈskraɪbd/
- Forma em **-ING**: **describing** → /dɪˈskraɪbɪŋ/

### Phrasal verbs

Não existem phrasal verbs relevantes derivados diretamente de **describe**.

### Forma em -ING

**describe → describing**

O verbo perde o **e** final antes de adicionar **-ING**.

- describe → describing

Pronúncia:

- describing → /dɪˈskraɪbɪŋ/

Exemplos:

- I am describing the problem.
  (Estou descrevendo o problema.)

- She is describing the solution.
  (Ela está descrevendo a solução.)

## Frases (tempo verbal)

### Presente (1ª pessoa)

I describe technical processes clearly.

(Eu descrevo processos técnicos claramente.)

### Presente (3ª pessoa)

She describes the requirements well.

(Ela descreve bem os requisitos.)

### Passado

I described the issue yesterday.

(Eu descrevi o problema ontem.)

### Futuro

I will describe the architecture tomorrow.

(Eu descreverei a arquitetura amanhã.)

### Particípio (Present Perfect)

I have described the solution.

(Eu descrevi a solução.)

## Estruturas importantes

### Estrutura principal

**describe + objeto**

Exemplos:

- Describe the problem.
  (Descreva o problema.)

- I described the process.
  (Eu descrevi o processo.)

- She described the application.
  (Ela descreveu a aplicação.)

### Outras formas comuns

#### describe + pessoa/coisa

- Can you describe the user?
  (Você pode descrever o usuário?)

- She described the interface.
  (Ela descreveu a interface.)

- He described the event.
  (Ele descreveu o evento.)

#### describe how + oração

- She described how the system works.
  (Ela descreveu como o sistema funciona.)

- We described how to configure the service.
  (Descrevemos como configurar o serviço.)

#### describe something as + característica

- He described the project as challenging.
  (Ele descreveu o projeto como desafiador.)

- The users described the software as intuitive.
  (Os usuários descreveram o software como intuitivo.)

## Uso com outros verbos

### Usa -ING?

- ✔ Sim

Exemplos:

- Describing technical details can be difficult.
  (Descrever detalhes técnicos pode ser difícil.)

- I enjoy describing complex ideas.
  (Eu gosto de descrever ideias complexas.)

- She is describing the workflow.
  (Ela está descrevendo o fluxo de trabalho.)

### Usa TO + infinitivo?

- ✔ Sim

Exemplos:

- I need to describe the issue.
  (Preciso descrever o problema.)

- We want to describe the process accurately.
  (Queremos descrever o processo com precisão.)

- She plans to describe the architecture in detail.
  (Ela planeja descrever a arquitetura em detalhes.)

### Preposição obrigatória?

Não possui preposição obrigatória.

A combinação mais comum é:

- describe something as something

Exemplos:

- They described the solution as effective.
  (Eles descreveram a solução como eficaz.)

- Users described the update as useful.
  (Os usuários descreveram a atualização como útil.)

## Frases extras (uso real)

- The engineer described the root cause of the issue.
  (O engenheiro descreveu a causa raiz do problema.)

- Please describe the error message in detail.
  (Por favor, descreva a mensagem de erro em detalhes.)

- The documentation describes how the API works.
  (A documentação descreve como a API funciona.)

- She described the deployment process step by step.
  (Ela descreveu o processo de implantação passo a passo.)

- The analyst described the findings in the report.
  (O analista descreveu as conclusões no relatório.)

## Combinações mais comuns (Collocations)

### describe a problem

- Can you describe the problem?
  (Você pode descrever o problema?)

### describe a process

- The document describes the process.
  (O documento descreve o processo.)

### describe in detail

- Please describe the issue in detail.
  (Por favor, descreva o problema em detalhes.)

### describe how something works

- She described how the software works.
  (Ela descreveu como o software funciona.)

### describe as

- Users described the application as reliable.
  (Os usuários descreveram a aplicação como confiável.)

## Expressões comuns

- describe a problem
- describe a process
- describe in detail
- describe how something works
- describe something as

## Erros comuns

❌ Describe me the process.

✔ Describe the process to me.

Após **describe**, normalmente o objeto vem antes da pessoa.

---

❌ She described me the issue.

✔ She described the issue to me.

A estrutura correta é **describe something to someone**.

---

❌ I have describe the solution.

✔ I have described the solution.

No Present Perfect, utiliza-se o particípio **described**.

## Observações importantes

- **Describe** significa fornecer detalhes sobre algo ou alguém.
- A estrutura **describe something to someone** é muito comum.
- Em TI, aparece frequentemente em documentação, requisitos, relatórios de incidentes, tickets de suporte e explicações técnicas.
- Expressões como **describe the issue**, **describe the process** e **describe the architecture** são extremamente comuns.
