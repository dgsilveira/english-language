## Verbo: DOWNLOAD

### Traduções principais
- baixar
- fazer download

### Informações gerais

**Outras traduções**
- transferir um arquivo da internet
- descarregar dados
- copiar arquivos de um servidor para um dispositivo

#### Palavras da mesma família

- download → download / transferência
- downloaded → baixado
- downloading → baixando
- downloader → programa de download
- upload → enviar arquivos

#### CEFR
- A2

#### Relevância para TI
- Muito usado

#### Tipo de verbo
- Regular

### Pronúncia (IPA – General American)

- Presente: **download** → /ˌdaʊnˈloʊd/
- Presente (3ª pessoa): **downloads** → /ˌdaʊnˈloʊdz/
- Passado: **downloaded** → /ˌdaʊnˈloʊdɪd/
- Particípio: **downloaded** → /ˌdaʊnˈloʊdɪd/
- Forma em **-ING**: **downloading** → /ˌdaʊnˈloʊdɪŋ/

### Phrasal verbs

Não existem phrasal verbs relevantes derivados diretamente de **download**.

### Forma em -ING

**download → downloading**

O verbo apenas recebe **-ING**.

- download → downloading

Pronúncia:

- downloading → /ˌdaʊnˈloʊdɪŋ/

Exemplos:

- I am downloading a file.
  (Estou baixando um arquivo.)

- She is downloading the update.
  (Ela está baixando a atualização.)

## Frases (tempo verbal)

### Presente (1ª pessoa)

I download files every day.

(Eu baixo arquivos todos os dias.)

### Presente (3ª pessoa)

She downloads reports regularly.

(Ela baixa relatórios regularmente.)

### Passado

I downloaded the software yesterday.

(Eu baixei o software ontem.)

### Futuro

I will download the document later.

(Eu baixarei o documento mais tarde.)

### Particípio (Present Perfect)

I have downloaded the latest version.

(Eu baixei a versão mais recente.)

## Estruturas importantes

### Estrutura principal

**download + objeto**

Exemplos:

- Download the file.
  (Baixe o arquivo.)

- I downloaded the application.
  (Eu baixei a aplicação.)

- She downloaded the document.
  (Ela baixou o documento.)

### Outras formas comuns

#### download + arquivo

- Download the PDF.
  (Baixe o PDF.)

- I downloaded the image.
  (Eu baixei a imagem.)

- We downloaded the dataset.
  (Nós baixamos o conjunto de dados.)

#### download + from + origem

- I downloaded it from the website.
  (Eu baixei isso do site.)

- She downloaded the package from GitHub.
  (Ela baixou o pacote do GitHub.)

- We downloaded the logs from the server.
  (Nós baixamos os logs do servidor.)

#### download + onto/to + dispositivo

- Download the file to your computer.
  (Baixe o arquivo para o seu computador.)

- She downloaded the app onto her phone.
  (Ela baixou o aplicativo para o celular dela.)

## Uso com outros verbos

### Usa -ING?

- ✔ Sim

Exemplos:

- I enjoy downloading new tools.
  (Eu gosto de baixar novas ferramentas.)

- Downloading large files takes time.
  (Baixar arquivos grandes leva tempo.)

- She is downloading a new version.
  (Ela está baixando uma nova versão.)

### Usa TO + infinitivo?

- ✔ Sim

Exemplos:

- I need to download the file.
  (Preciso baixar o arquivo.)

- We want to download the report.
  (Queremos baixar o relatório.)

- She plans to download the update tonight.
  (Ela planeja baixar a atualização esta noite.)

### Preposição obrigatória?

Não possui preposição obrigatória.

As mais comuns são:

- from
- to
- onto

Exemplos:

- Download the file from the server.
  (Baixe o arquivo do servidor.)

- Download the report to your computer.
  (Baixe o relatório para o seu computador.)

- She downloaded the app onto her phone.
  (Ela baixou o aplicativo para o celular dela.)

## Frases extras (uso real)

- Please download the latest version of the software.
  (Por favor, baixe a versão mais recente do software.)

- We downloaded the backup before the migration.
  (Baixamos o backup antes da migração.)

- The user downloaded the installation package.
  (O usuário baixou o pacote de instalação.)

- I downloaded the logs for analysis.
  (Baixei os logs para análise.)

- The application automatically downloads updates.
  (A aplicação baixa atualizações automaticamente.)

## Combinações mais comuns (Collocations)

### download a file

- Please download the file before the meeting.
  (Por favor, baixe o arquivo antes da reunião.)

### download software

- I downloaded the software yesterday.
  (Eu baixei o software ontem.)

### download an update

- The system downloaded an update automatically.
  (O sistema baixou uma atualização automaticamente.)

### download a document

- She downloaded the document from SharePoint.
  (Ela baixou o documento do SharePoint.)

### download data

- The analyst downloaded the data for review.
  (O analista baixou os dados para revisão.)

## Expressões comuns

- download a file
- download software
- download an update
- download data
- download from a website

## Erros comuns

❌ I have download the file.

✔ I have downloaded the file.

No Present Perfect, utiliza-se o particípio **downloaded**.

---

❌ Download the file in the website.

✔ Download the file from the website.

A preposição correta é **from**.

---

❌ I downloaded to my phone the app.

✔ I downloaded the app to my phone.

A ordem mais natural é **download + objeto + to + destino**.

## Observações importantes

- **Download** é o oposto de **upload**.
- Em TI, é um dos verbos mais utilizados para arquivos, documentos, aplicativos, atualizações e dados.
- As estruturas mais importantes são **download a file**, **download from** e **download to**.
