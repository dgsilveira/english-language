# Verbo: READ

## Traduções principais
- ler

---

## Informações gerais

### Outras traduções

- interpretar
- examinar
- consultar
- analisar informações escritas

### Palavras da mesma família

- read → ler
- reader → leitor
- reading → leitura
- readable → legível
- unread → não lido

### CEFR

- A1

### Relevância para TI

- Extremamente usado

### Tipo de verbo

- Irregular

---

## Pronúncia (IPA – General American)

### Atenção

A escrita é a mesma, mas a pronúncia muda.

| Forma | Pronúncia |
|---------|---------|
| read (presente) | /riːd/ |
| reads | /riːdz/ |
| read (passado) | /red/ |
| read (particípio) | /red/ |
| reading | /ˈriːdɪŋ/ |

---

## Forma em -ING

**read → reading**

Exemplos:

- I am reading a book.
  (Estou lendo um livro.)

- She is reading documentation.
  (Ela está lendo documentação.)

---

## Frases (tempo verbal)

### Presente (1ª pessoa)

I read every day.

(Eu leio todos os dias.)

### Presente (3ª pessoa)

She reads technical articles.

(Ela lê artigos técnicos.)

### Passado

I read the report yesterday.

(Eu li o relatório ontem.)

> Pronúncia: **/red/**

### Futuro

I will read the documentation.

(Eu lerei a documentação.)

### Particípio (Present Perfect)

I have read the entire guide.

(Eu li o guia inteiro.)

> Pronúncia: **/red/**

---

## Estruturas importantes

### Estrutura principal

**read + objeto**

Exemplos:

- Read the book.
  (Leia o livro.)

- Read the report.
  (Leia o relatório.)

- Read the instructions.
  (Leia as instruções.)

### Outras formas comuns

#### read a book

- I read books regularly.
  (Eu leio livros regularmente.)

- She read three books last month.
  (Ela leu três livros no mês passado.)

#### read documentation

Muito comum em TI.

- Developers should read the documentation.
  (Desenvolvedores devem ler a documentação.)

- I read the API documentation.
  (Eu li a documentação da API.)

#### read emails

- I read my emails every morning.
  (Eu leio meus e-mails todas as manhãs.)

- She hasn't read the message yet.
  (Ela ainda não leu a mensagem.)

---

## Uso com outros verbos

### Usa -ING?

✅ Sim.

Exemplos:

- Reading improves vocabulary.
  (Ler melhora o vocabulário.)

- I enjoy reading technical books.
  (Eu gosto de ler livros técnicos.)

- She is reading the project requirements.
  (Ela está lendo os requisitos do projeto.)

### Usa TO + infinitivo?

✅ Sim.

Exemplos:

- I want to read this book.
  (Quero ler este livro.)

- We need to read the report.
  (Precisamos ler o relatório.)

- She plans to read the documentation later.
  (Ela planeja ler a documentação mais tarde.)

---

## Preposição obrigatória?

Não possui.

Exemplos:

- Read the file.
  (Leia o arquivo.)

- Read the article.
  (Leia o artigo.)

- Read the message.
  (Leia a mensagem.)

---

## Frases extras (uso real)

- Please read the instructions carefully.
  (Por favor, leia as instruções cuidadosamente.)

- I read the release notes before updating.
  (Eu li as notas da versão antes de atualizar.)

- Developers often read documentation to solve problems.
  (Desenvolvedores frequentemente leem documentação para resolver problemas.)

- She read the error message and found the solution.
  (Ela leu a mensagem de erro e encontrou a solução.)

- We need to read the requirements before starting development.
  (Precisamos ler os requisitos antes de iniciar o desenvolvimento.)

## Erros comuns

❌ I have readed the report.

✔ I have read the report.

O particípio correto é **read**.

---

❌ Yesterday I readed the book.

✔ Yesterday I read the book.

A escrita permanece igual; apenas a pronúncia muda.

---

❌ She read technical articles every day.

✔ She reads technical articles every day.

Na 3ª pessoa do singular, adiciona-se **-s**.

---

## Observações importantes

- As formas do verbo são:

| Tempo | Forma | Pronúncia |
|---------|---------|---------|
| Presente | read | /riːd/ |
| Passado | read | /red/ |
| Particípio | read | /red/ |

Exemplos:

- I **read** books every day.
  (/riːd/)
  Eu leio livros todos os dias.

- I **read** that book yesterday.
  (/red/)
  Eu li aquele livro ontem.

- I have **read** the documentation.
  (/red/)
  Eu li a documentação.

- Em TI, aparece constantemente em expressões como:

  - read documentation
  - read logs
  - read data
  - read emails
  - read requirements

### Frase clássica

**Read the documentation before asking for help.**

➡️ **Leia a documentação antes de pedir ajuda.**
