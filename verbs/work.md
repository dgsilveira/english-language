# Verbo: WORK

## Traduções principais
- trabalhar
- funcionar

### Informações gerais

**Outras traduções**
- operar
- dar certo
- exercer atividade
- produzir resultado

#### Palavras da mesma família

- work → trabalho
- worker → trabalhador
- working → trabalhando
- workplace → local de trabalho
- workflow → fluxo de trabalho

#### CEFR
- A1

#### Relevância para TI
- Extremamente usado

#### Tipo de verbo

- Regular

### Pronúncia (IPA – General American)

- Presente: **work** → /wɝːk/
- Presente (3ª pessoa): **works** → /wɝːks/
- Passado: **worked** → /wɝːkt/
- Particípio: **worked** → /wɝːkt/
- Forma em **-ING**: **working** → /ˈwɝːkɪŋ/

### Phrasal verbs

- work out
- work on
- work through
- work around
- work for

### Forma em -ING

**work → working**

O verbo apenas recebe **-ING**.

Exemplos:

- I am working right now.
  (Estou trabalhando agora.)

- The application is working correctly.
  (A aplicação está funcionando corretamente.)

## Frases (tempo verbal)

### Presente (1ª pessoa)

I work from home.

(Eu trabalho de casa.)

### Presente (3ª pessoa)

She works for a software company.

(Ela trabalha para uma empresa de software.)

### Passado

I worked on the project last week.

(Eu trabalhei no projeto na semana passada.)

### Futuro

I will work on the task tomorrow.

(Eu trabalharei na tarefa amanhã.)

### Particípio (Present Perfect)

I have worked with many teams.

(Eu trabalhei com muitas equipes.)

## Estruturas importantes

### Estrutura principal

**work + complemento**

Exemplos:

- Work hard.
  (Trabalhe duro.)

- I work remotely.
  (Eu trabalho remotamente.)

- She works efficiently.
  (Ela trabalha de forma eficiente.)

### Outras formas comuns

#### work on

- I am working on a new feature.
  (Estou trabalhando em um novo recurso.)

- She worked on the documentation.
  (Ela trabalhou na documentação.)

- We are working on the issue.
  (Estamos trabalhando no problema.)

#### work with

- I work with developers.
  (Eu trabalho com desenvolvedores.)

- She works with cloud technologies.
  (Ela trabalha com tecnologias de nuvem.)

- We worked with external consultants.
  (Trabalhamos com consultores externos.)

#### work for

- I work for a technology company.
  (Eu trabalho para uma empresa de tecnologia.)

- She works for Microsoft.
  (Ela trabalha para a Microsoft.)

#### work properly

- The application works properly.
  (A aplicação funciona corretamente.)

- Everything worked as expected.
  (Tudo funcionou como esperado.)

## Uso com outros verbos

### Usa -ING?

✔ Sim

Exemplos:

- Working remotely has many benefits.
  (Trabalhar remotamente tem muitos benefícios.)

- I enjoy working with technology.
  (Gosto de trabalhar com tecnologia.)

- They are working on a solution.
  (Eles estão trabalhando em uma solução.)

### Usa TO + infinitivo?

✔ Sim

Exemplos:

- I want to work here.
  (Quero trabalhar aqui.)

- We need to work together.
  (Precisamos trabalhar juntos.)

- She plans to work abroad.
  (Ela planeja trabalhar no exterior.)

### Preposição obrigatória?

Não possui.

Mas são muito comuns:

- work on
- work with
- work for

Exemplos:

- Work on the project.
  (Trabalhe no projeto.)

- Work with the team.
  (Trabalhe com a equipe.)

- Work for the company.
  (Trabalhe para a empresa.)

## Frases extras (uso real)

- The system works without any issues.
  (O sistema funciona sem problemas.)

  (Os desenvolvedores estão trabalhando em uma correção.)

- This solution works well in production.

- We worked together to solve the incident.
  (Trabalhamos juntos para resolver o incidente.)

  (A API funciona com vários métodos de autenticação.)

## Expressões comuns

- work on
- work with
- work for
- work hard
- work well

## Erros comuns

❌ The application work correctly.

✔ The application works correctly.

Na 3ª pessoa do singular, adiciona-se **-s**.

---

❌ I have work on this project.

✔ I have worked on this project.

No Present Perfect, utiliza-se **worked**.

---

❌ We work in solve the issue.

✔ We work to solve the issue.

✔ We are working on solving the issue.

As estruturas corretas são **work to + verbo** ou **work on + ING**.

## Observações importantes

- **Work** pode significar tanto **trabalhar** quanto **funcionar**.
- Em TI, uma das frases mais comuns é: **"It works!"** (Funciona!).
- As expressões **work on**, **work with** e **work for** aparecem constantemente no ambiente profissional.
