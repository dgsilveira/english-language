# Verbo: PUSH

## Traduções principais
- empurrar

---

## Informações gerais

### Outras traduções

- pressionar para frente
- impulsionar
- forçar um avanço
- enviar (em contextos técnicos)

### Palavras da mesma família

- push → empurrão
- pushed → empurrado
- pushing → empurrando
- pushy → insistente
- pushbutton → botão de pressão

### CEFR

- A2

### Relevância para TI

- Extremamente usado

### Tipo de verbo

- Regular

---

## Pronúncia (IPA – General American)

- Presente: **push** → /pʊʃ/
- Presente (3ª pessoa): **pushes** → /ˈpʊʃɪz/
- Passado: **pushed** → /pʊʃt/
- Particípio: **pushed** → /pʊʃt/
- Forma em **-ING**: **pushing** → /ˈpʊʃɪŋ/

---

## Forma em -ING

**push → pushing**

Exemplos:

- I am pushing the door.
  (Estou empurrando a porta.)

- The team is pushing updates.
  (A equipe está enviando atualizações.)

---

## Frases (tempo verbal)

### Presente (1ª pessoa)

I push for improvements.

(Eu pressiono por melhorias.)

### Presente (3ª pessoa)

She pushes the cart.

(Ela empurra o carrinho.)

### Passado

I pushed the change yesterday.

(Eu enviei a alteração ontem.)

### Futuro

I will push the update tonight.

(Eu enviarei a atualização esta noite.)

### Particípio (Present Perfect)

I have pushed the latest code.

(Eu enviei o código mais recente.)

---

## Estruturas importantes

### Estrutura principal

**push + objeto**

Exemplos:

- Push the door.
  (Empurre a porta.)

- Push the button.
  (Empurre/pressione o botão.)

- Push the cart.
  (Empurre o carrinho.)

### Outras formas comuns

#### push for

Muito comum em negócios e TI.

- We pushed for a faster solution.
  (Pressionamos por uma solução mais rápida.)

- Management pushed for better results.
  (A gerência pressionou por melhores resultados.)

#### push an update

- The team pushed a new update.
  (A equipe publicou uma nova atualização.)

- We pushed a hotfix to production.
  (Enviamos uma correção urgente para produção.)

#### push code

Muito comum com Git.

- I pushed my changes to GitHub.
  (Enviei minhas alterações para o GitHub.)

- Developers should push code regularly.
  (Desenvolvedores devem enviar código regularmente.)

---

## Uso com outros verbos

### Usa -ING?

✅ Sim.

Exemplos:

- Pushing code frequently reduces conflicts.
  (Enviar código frequentemente reduz conflitos.)

- I enjoy pushing new features.
  (Gosto de publicar novos recursos.)

- The company is pushing innovation.
  (A empresa está impulsionando a inovação.)

### Usa TO + infinitivo?

✅ Sim.

Exemplos:

- I need to push the update.
  (Preciso enviar a atualização.)

- We want to push the release today.
  (Queremos publicar a versão hoje.)

- She plans to push the changes tomorrow.
  (Ela planeja enviar as alterações amanhã.)

---

## Preposição obrigatória?

Não possui.

Mas são comuns:

- push for
- push to
- push through

Exemplos:

- Push for improvements.
  (Pressionar por melhorias.)

- Push code to GitHub.
  (Enviar código para o GitHub.)

- Push the proposal through.
  (Fazer a proposta avançar.)

## Erros comuns

❌ I have push the update.

✔ I have pushed the update.

No Present Perfect, utiliza-se **pushed**.

---

❌ She push code daily.

✔ She pushes code daily.

Na 3ª pessoa do singular, adiciona-se **-es**.

---

❌ We pushed for to improve.

✔ We pushed for improvements.

✔ We pushed to improve.

As estruturas são diferentes e não devem ser misturadas.

---

## Observações importantes

- **Push** é o oposto de **pull**:

| Verbo | Significado |
|---------|------------|
| push | empurrar / enviar |
| pull | puxar / buscar |

### Em Git

- **git push** → envia alterações para o repositório remoto.
- **git pull** → baixa alterações do repositório remoto.

### Muito comum em TI

- push code
- push changes
- push updates
- push notifications
- push a release

### Frase clássica

**Don't forget to push your changes.**

➡️ **Não se esqueça de enviar suas alterações.**
