## Verbo: FIX

### Traduções principais
- consertar
- corrigir

### Informações gerais

**Outras traduções**
- reparar
- resolver
- ajustar
- tornar funcional novamente

#### Palavras da mesma família

- fix → correção / conserto
- fixed → corrigido
- fixing → corrigindo
- fixer → reparador
- bug fix → correção de bug

#### CEFR
- A1

#### Relevância para TI
- Muito usado

#### Tipo de verbo
- Regular

### Pronúncia (IPA – General American)

- Presente: **fix** → /fɪks/
- Presente (3ª pessoa): **fixes** → /ˈfɪksɪz/
- Passado: **fixed** → /fɪkst/
- Particípio: **fixed** → /fɪkst/
- Forma em **-ING**: **fixing** → /ˈfɪksɪŋ/

### Phrasal verbs

- fix up
- fix on

### Forma em -ING

**fix → fixing**

O verbo apenas recebe **-ING**.

- fix → fixing

Pronúncia:

- fixing → /ˈfɪksɪŋ/

Exemplos:

- I am fixing a bug.
  (Estou corrigindo um bug.)

- She is fixing the configuration.
  (Ela está corrigindo a configuração.)

## Frases (tempo verbal)

### Presente (1ª pessoa)

I fix software issues.

(Eu corrijo problemas de software.)

### Presente (3ª pessoa)

She fixes bugs quickly.

(Ela corrige bugs rapidamente.)

### Passado

I fixed the issue yesterday.

(Eu corrigi o problema ontem.)

### Futuro

I will fix the problem tomorrow.

(Eu corrigirei o problema amanhã.)

### Particípio (Present Perfect)

I have fixed the bug.

(Eu corrigi o bug.)

## Estruturas importantes

### Estrutura principal

**fix + objeto**

Exemplos:

- Fix the problem.
  (Corrija o problema.)

- I fixed the application.
  (Eu corrigi a aplicação.)

- She fixed the error.
  (Ela corrigiu o erro.)

### Outras formas comuns

#### fix a bug

Muito comum em TI.

- I fixed the bug.
  (Eu corrigi o bug.)

- The developer fixed a critical bug.
  (O desenvolvedor corrigiu um bug crítico.)

- We fixed several bugs before release.
  (Corrigimos vários bugs antes da entrega.)

#### fix an issue

- The team fixed the issue.
  (A equipe corrigiu o problema.)

- She fixed the login issue.
  (Ela corrigiu o problema de login.)

- We need to fix the outage.
  (Precisamos resolver a indisponibilidade.)

#### fix a configuration

- I fixed the configuration.
  (Eu corrigi a configuração.)

- The administrator fixed the network settings.
  (O administrador corrigiu as configurações de rede.)

## Uso com outros verbos

### Usa -ING?

- ✔ Sim

Exemplos:

- I enjoy fixing problems.
  (Eu gosto de corrigir problemas.)

- Fixing bugs takes patience.
  (Corrigir bugs exige paciência.)

- She is fixing the deployment issue.
  (Ela está corrigindo o problema de implantação.)

### Usa TO + infinitivo?

- ✔ Sim

Exemplos:

- I need to fix this error.
  (Preciso corrigir este erro.)

- We want to fix the issue today.
  (Queremos corrigir o problema hoje.)

- She plans to fix the server tomorrow.
  (Ela planeja corrigir o servidor amanhã.)

### Preposição obrigatória?

Não possui preposição obrigatória.

Exemplos:

- Fix the bug.
  (Corrija o bug.)

- Fix the application.
  (Corrija a aplicação.)

- Fix the configuration.
  (Corrija a configuração.)

## Expressões comuns

- fix a bug

## Erros comuns

❌ I have fix the issue.

✔ I have fixed the issue.

No Present Perfect, utiliza-se o particípio **fixed**.

---

❌ She fixeded the bug.

✔ She fixed the bug.

O passado correto é **fixed**.

---

❌ We fixed on the problem.

✔ We fixed the problem.

**Fix** normalmente recebe o objeto diretamente.

## Observações importantes

- **Fix** é um dos verbos mais usados na área de TI.
- Expressões como **fix a bug**, **fix an issue** e **fix a problem** aparecem diariamente em desenvolvimento e suporte.
- Em commit messages de software, é extremamente comum ver apenas: **"Fix bug"**, **"Fix login issue"** ou **"Fixed performance problem"**.
