# Verbo: USE

## Traduções principais
- usar
- utilizar

### Informações gerais

**Outras traduções**
- empregar
- aplicar
- fazer uso de
- servir-se de

#### Palavras da mesma família

- use → uso
- used → usado
- using → usando
- useful → útil
- useless → inútil

#### CEFR
- A1

#### Relevância para TI
- Extremamente usado

#### Tipo de verbo

- Regular

### Pronúncia (IPA – General American)

- Presente: **use** → /juːz/
- Presente (3ª pessoa): **uses** → /ˈjuːzɪz/
- Passado: **used** → /juːzd/
- Particípio: **used** → /juːzd/
- Forma em **-ING**: **using** → /ˈjuːzɪŋ/

### Phrasal verbs

Não existem phrasal verbs realmente relevantes para **use**.

### Forma em -ING

**use → using**

O verbo perde o **e** final antes de adicionar **-ING**.

Exemplos:

- I am using a new tool.
  (Estou usando uma nova ferramenta.)

- She is using the application.
  (Ela está usando a aplicação.)

## Frases (tempo verbal)

### Presente (1ª pessoa)

I use this tool every day.

(Eu uso esta ferramenta todos os dias.)

### Presente (3ª pessoa)

She uses the system regularly.

(Ela usa o sistema regularmente.)

### Passado

I used the application yesterday.

(Eu usei a aplicação ontem.)

### Futuro

I will use the new feature.

(Eu usarei o novo recurso.)

### Particípio (Present Perfect)

I have used this framework before.

(Eu já usei este framework antes.)

## Estruturas importantes

### Estrutura principal

**use + objeto**

Exemplos:

- Use the tool.
  (Use a ferramenta.)

- I used the software.
  (Eu usei o software.)

- She uses the platform.
  (Ela usa a plataforma.)

### Outras formas comuns

#### use something for

- I use this laptop for work.
  (Eu uso este notebook para trabalhar.)

- She uses Python for automation.
  (Ela usa Python para automação.)

- We use cloud services for storage.
  (Usamos serviços de nuvem para armazenamento.)

#### use something to + verbo

- I use Git to manage code.
  (Eu uso Git para gerenciar código.)

- She uses a script to automate tasks.
  (Ela usa um script para automatizar tarefas.)

- We use APIs to exchange data.
  (Usamos APIs para trocar dados.)

#### use a tool

- Developers use version control systems.
  (Desenvolvedores usam sistemas de controle de versão.)

- We use monitoring tools daily.
  (Usamos ferramentas de monitoramento diariamente.)

## Uso com outros verbos

### Usa -ING?

✔ Sim

Exemplos:

- Using automation saves time.
  (Usar automação economiza tempo.)

- I enjoy using new technologies.
  (Gosto de usar novas tecnologias.)

- They are using the new platform.
  (Eles estão usando a nova plataforma.)

### Usa TO + infinitivo?

✔ Sim

Exemplos:

- I want to use this tool.
  (Quero usar esta ferramenta.)

- We need to use the correct configuration.
  (Precisamos usar a configuração correta.)

- She plans to use the new feature.
  (Ela planeja usar o novo recurso.)

### Preposição obrigatória?

Não possui.

Mas são comuns:

- use for
- use to

Exemplos:

- Use this tool for testing.
  (Use esta ferramenta para testes.)

- Use the script to automate tasks.
  (Use o script para automatizar tarefas.)

## Frases extras (uso real)

- Developers use Git to manage source code.
  (Desenvolvedores usam Git para gerenciar código-fonte.)

- We use automated tests before deployment.
  (Usamos testes automatizados antes da implantação.)

- The application uses a secure authentication method.
  (A aplicação utiliza um método seguro de autenticação.)

- Many companies use cloud platforms to reduce costs.
  (Muitas empresas usam plataformas de nuvem para reduzir custos.)

- Users can use the dashboard to monitor system health.
  (Os usuários podem usar o painel para monitorar a saúde do sistema.)

## Combinações mais comuns (Collocations)

### use a tool

- I use a tool to analyze logs.
  (Eu uso uma ferramenta para analisar logs.)

### use software

- Many companies use software to manage projects.
  (Muitas empresas usam software para gerenciar projetos.)

### use a system

- Employees use the system every day.
  (Os funcionários usam o sistema todos os dias.)

### use data

- The application uses data from multiple sources.
  (A aplicação utiliza dados de múltiplas fontes.)

### use an API

- Developers use an API to integrate services.
  (Desenvolvedores usam uma API para integrar serviços.)

## Expressões comuns

- use a tool
- use software
- use an API
- use data
- use common sense

## Erros comuns

❌ I have use this tool before.

✔ I have used this tool before.

No Present Perfect, utiliza-se **used**.

---

❌ She use the system every day.

✔ She uses the system every day.

Na 3ª pessoa do singular, adiciona-se **-s**.

---

❌ I use this tool for automate tasks.

✔ I use this tool to automate tasks.

✔ I use this tool for automation.

Após **use**, a estrutura correta é **use something to + verbo**.

## Observações importantes

- **Use** é um dos verbos mais frequentes do inglês, especialmente em ambientes profissionais e de TI.
- As estruturas **use something for** e **use something to + verbo** são extremamente importantes.
- Em TI, aparece constantemente em expressões como **use a tool**, **use an API**, **use software** e **use data**.
