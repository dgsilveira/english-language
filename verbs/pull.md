# Verbo: PULL

## Traduções principais
- puxar

---

## Informações gerais

### Outras traduções

- arrastar
- retirar
- remover
- puxar para perto

### Palavras da mesma família

- pull → puxão
- pulled → puxado
- pulling → puxando
- pullout → retirada
- pullback → recuo

### CEFR

- A2

### Relevância para TI

- Muito usado

### Tipo de verbo

- Regular

---

## Pronúncia (IPA – General American)

- Presente: **pull** → /pʊl/
- Presente (3ª pessoa): **pulls** → /pʊlz/
- Passado: **pulled** → /pʊld/
- Particípio: **pulled** → /pʊld/
- Forma em **-ING**: **pulling** → /ˈpʊlɪŋ/

---

## Forma em -ING

**pull → pulling**

Exemplos:

- I am pulling the door open.
  (Estou puxando a porta para abrir.)

- The system is pulling data from the server.
  (O sistema está buscando dados do servidor.)

---

## Frases (tempo verbal)

### Presente (1ª pessoa)

I pull the handle carefully.

(Eu puxo a maçaneta com cuidado.)

### Presente (3ª pessoa)

She pulls the cable gently.

(Ela puxa o cabo com cuidado.)

### Passado

I pulled the wrong file.

(Eu retirei o arquivo errado.)

### Futuro

I will pull the report later.

(Eu buscarei o relatório mais tarde.)

### Particípio (Present Perfect)

I have pulled the latest changes.

(Eu baixei as alterações mais recentes.)

---

## Estruturas importantes

### Estrutura principal

**pull + objeto**

Exemplos:

- Pull the rope.
  (Puxe a corda.)

- Pull the door.
  (Puxe a porta.)

- Pull the cable.
  (Puxe o cabo.)

### Outras formas comuns

#### pull data

Muito comum em TI.

- The application pulls data from an API.
  (A aplicação busca dados de uma API.)

- The script pulls information automatically.
  (O script busca informações automaticamente.)

#### pull a report

- I pulled a report from the database.
  (Extraí um relatório do banco de dados.)

- She pulled the latest metrics.
  (Ela obteve as métricas mais recentes.)

#### pull changes

Muito comum com Git.

- Pull the latest changes before starting.
  (Baixe as alterações mais recentes antes de começar.)

- Developers should pull frequently.
  (Os desenvolvedores devem atualizar frequentemente.)

---

## Uso com outros verbos

### Usa -ING?

✅ Sim.

Exemplos:

- Pulling data from multiple sources can be slow.
  (Buscar dados de várias fontes pode ser lento.)

- I enjoy pulling statistics from databases.
  (Gosto de extrair estatísticas de bancos de dados.)

- The system is pulling logs continuously.
  (O sistema está coletando logs continuamente.)

### Usa TO + infinitivo?

✅ Sim.

Exemplos:

- I need to pull the latest code.
  (Preciso baixar o código mais recente.)

- We want to pull the report.
  (Queremos obter o relatório.)

- She plans to pull the data tomorrow.
  (Ela planeja buscar os dados amanhã.)

---

## Preposição obrigatória?

Não possui.

Mas são comuns:

- pull from
- pull out
- pull over
- pull up

Exemplos:

- Pull data from the database.
  (Buscar dados do banco de dados.)

- Pull out the cable.
  (Retire o cabo.)

## Erros comuns

❌ I have pull the report.

✔ I have pulled the report.

No Present Perfect, utiliza-se **pulled**.

---

❌ She pulls from the cable.

✔ She pulls the cable.

Normalmente **pull** recebe o objeto diretamente.

---

❌ We pulled the changes from.

✔ We pulled the changes from GitHub.

A origem deve ser especificada após **from**.

---

## Observações importantes

- **Pull** significa puxar fisicamente algo, mas em TI frequentemente significa:
  - buscar dados
  - baixar informações
  - obter registros
  - sincronizar alterações

- Expressões muito comuns em TI:

  - **pull data**
  - **pull logs**
  - **pull a report**
  - **pull changes**
  - **git pull**

### Frase clássica

**Pull the latest changes before you start working.**

➡️ **Baixe as alterações mais recentes antes de começar a trabalhar.**
