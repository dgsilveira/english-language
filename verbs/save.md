# Verbo: SAVE

## Traduções principais
- salvar
- economizar

---

## Informações gerais

### Outras traduções

- guardar
- armazenar
- preservar
- poupar
- resgatar

### Palavras da mesma família

- save → salvar / economizar
- saved → salvo
- saving → salvando / economia
- savings → economias
- lifesaver → salvador

### CEFR

- A1

### Relevância para TI

- Extremamente usado

### Tipo de verbo

- Regular

---

## Pronúncia (IPA – General American)

- Presente: **save** → /seɪv/
- Presente (3ª pessoa): **saves** → /seɪvz/
- Passado: **saved** → /seɪvd/
- Particípio: **saved** → /seɪvd/
- Forma em **-ING**: **saving** → /ˈseɪvɪŋ/

---

## Forma em -ING

**save → saving**

O verbo perde o **e** final antes de adicionar **-ING**.

- save → saving

Exemplos:

- I am saving the file.
  (Estou salvando o arquivo.)

- She is saving money.
  (Ela está economizando dinheiro.)

---

## Frases (tempo verbal)

### Presente (1ª pessoa)

I save my work frequently.

(Eu salvo meu trabalho frequentemente.)

### Presente (3ª pessoa)

She saves every document.

(Ela salva todos os documentos.)

### Passado

I saved the file.

(Eu salvei o arquivo.)

### Futuro

I will save the report.

(Eu salvarei o relatório.)

### Particípio (Present Perfect)

I have saved the document.

(Eu salvei o documento.)

---

## Estruturas importantes

### Estrutura principal

**save + objeto**

Exemplos:

- Save the file.
  (Salve o arquivo.)

- Save the document.
  (Salve o documento.)

- Save your work.
  (Salve seu trabalho.)

### Outras formas comuns

#### save a file

- Remember to save the file.
  (Lembre-se de salvar o arquivo.)

- I saved the spreadsheet.
  (Eu salvei a planilha.)

#### save data

Muito comum em TI.

- The application saves data automatically.
  (A aplicação salva dados automaticamente.)

- We saved the information in the database.
  (Salvamos as informações no banco de dados.)

#### save money

- I save money every month.
  (Eu economizo dinheiro todos os meses.)

- She is saving for a new laptop.
  (Ela está economizando para um novo notebook.)

#### save time

- Automation saves time.
  (A automação economiza tempo.)

- The new process saved hours of work.
  (O novo processo economizou horas de trabalho.)

---

## Uso com outros verbos

### Usa -ING?

✅ Sim.

Exemplos:

- Saving files regularly prevents data loss.
  (Salvar arquivos regularmente evita perda de dados.)

- I enjoy saving useful resources.
  (Gosto de guardar recursos úteis.)

- The application is saving data in the background.
  (A aplicação está salvando dados em segundo plano.)

### Usa TO + infinitivo?

✅ Sim.

Exemplos:

- I need to save this file.
  (Preciso salvar este arquivo.)

- We want to save time.
  (Queremos economizar tempo.)

- She plans to save more money.
  (Ela planeja economizar mais dinheiro.)

---

## Preposição obrigatória?

Não possui.

Mas são comuns:

- save for
- save from

Exemplos:

- I am saving for a new computer.
  (Estou economizando para um novo computador.)

- The backup saved us from losing data.
  (O backup nos salvou de perder dados.)

## Erros comuns

❌ I have save the file.

✔ I have saved the file.

No Present Perfect, utiliza-se **saved**.

---

❌ She save her work frequently.

✔ She saves her work frequently.

Na 3ª pessoa do singular, adiciona-se **-s**.

---

❌ Don't forget save the file.

✔ Don't forget to save the file.

Após **forget**, usa-se normalmente **to + verbo**.

---

## Observações importantes

- **Save** possui dois significados muito comuns:

### 1. Salvar / armazenar

- Save the file.
  (Salve o arquivo.)

- Save the document.
  (Salve o documento.)

### 2. Economizar / poupar

- Save money.
  (Economizar dinheiro.)

- Save time.
  (Economizar tempo.)

- Em TI, aparece constantemente em expressões como:

  - save a file
  - save changes
  - save data
  - save settings
  - auto-save

### Frase clássica

**Don't forget to save your work.**

➡️ **Não se esqueça de salvar seu trabalho.**
