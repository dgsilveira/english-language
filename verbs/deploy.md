## Verbo: DEPLOY

### Traduções principais
- implantar
- fazer deploy

### Informações gerais

**Outras traduções**
- colocar em produção
- disponibilizar
- lançar uma versão
- distribuir um sistema ou aplicação

#### Palavras da mesma família

- deployment → implantação / deploy
- deployed → implantado
- deploying → implantando
- deployable → implantável
- redeploy → reimplantar

#### CEFR
- B2

#### Relevância para TI
- Extremamente usado

#### Tipo de verbo
- Regular

### Pronúncia (IPA – General American)

- Presente: **deploy** → /dɪˈplɔɪ/
- Presente (3ª pessoa): **deploys** → /dɪˈplɔɪz/
- Passado: **deployed** → /dɪˈplɔɪd/
- Particípio: **deployed** → /dɪˈplɔɪd/
- Forma em **-ING**: **deploying** → /dɪˈplɔɪɪŋ/

### Phrasal verbs

Não existem phrasal verbs relevantes derivados diretamente de **deploy**.

### Forma em -ING

**deploy → deploying**

O verbo apenas recebe **-ING**.

- deploy → deploying

Pronúncia:

- deploying → /dɪˈplɔɪɪŋ/

Exemplos:

- We are deploying a new version.
  (Estamos implantando uma nova versão.)

- She is deploying the application.
  (Ela está implantando a aplicação.)

## Frases (tempo verbal)

### Presente (1ª pessoa)

I deploy applications regularly.

(Eu implanto aplicações regularmente.)

### Presente (3ª pessoa)

She deploys updates every week.

(Ela implanta atualizações toda semana.)

### Passado

I deployed the application yesterday.

(Eu implantei a aplicação ontem.)

### Futuro

I will deploy the new version tomorrow.

(Eu implantarei a nova versão amanhã.)

### Particípio (Present Perfect)

I have deployed the solution.

(Eu implantei a solução.)

## Estruturas importantes

### Estrutura principal

**deploy + objeto**

Exemplos:

- Deploy the application.
  (Implante a aplicação.)

- I deployed the update.
  (Eu implantei a atualização.)

- She deployed the service.
  (Ela implantou o serviço.)

### Outras formas comuns

#### deploy an application

- We deployed the application successfully.
  (Implantamos a aplicação com sucesso.)

- The team deployed the mobile app.
  (A equipe implantou o aplicativo móvel.)

#### deploy a new version

- We deployed a new version last night.
  (Implantamos uma nova versão ontem à noite.)

- She deployed version 2.0.
  (Ela implantou a versão 2.0.)

#### deploy to production

Estrutura extremamente comum em TI.

- We deployed to production.
  (Fizemos deploy em produção.)

- The application was deployed to production.
  (A aplicação foi implantada em produção.)

- She deployed the update to production.
  (Ela implantou a atualização em produção.)

## Uso com outros verbos

### Usa -ING?

- ✔ Sim

Exemplos:

- Deploying software requires planning.
  (Implantar software exige planejamento.)

- I enjoy deploying new features.
  (Eu gosto de implantar novos recursos.)

- The team is deploying the system now.
  (A equipe está implantando o sistema agora.)

### Usa TO + infinitivo?

- ✔ Sim

Exemplos:

- We need to deploy the application.
  (Precisamos implantar a aplicação.)

- I want to deploy the update today.
  (Quero implantar a atualização hoje.)

- She plans to deploy the service tonight.
  (Ela planeja implantar o serviço esta noite.)

### Preposição obrigatória?

Não possui preposição obrigatória.

As combinações mais comuns são:

- deploy to
- deploy on

Exemplos:

- Deploy to production.
  (Implante em produção.)

- Deploy to the cloud.
  (Implante na nuvem.)

- Deploy on Kubernetes.
  (Implante no Kubernetes.)

## Frases extras (uso real)

- The team deployed the application without downtime.
  (A equipe implantou a aplicação sem indisponibilidade.)

- We need to deploy the hotfix immediately.
  (Precisamos implantar a correção imediatamente.)

- The engineer deployed the container to Kubernetes.
  (O engenheiro implantou o contêiner no Kubernetes.)

- The system was deployed to the cloud.
  (O sistema foi implantado na nuvem.)

- We successfully deployed the new release.
  (Implantamos com sucesso a nova versão.)

## Combinações mais comuns (Collocations)

### deploy an application

  (Implantamos a aplicação em produção.)

### deploy a service

  (O administrador implantou um novo serviço.)

### deploy an update

- She deployed the update successfully.
  (Ela implantou a atualização com sucesso.)

### deploy to production

  (A versão foi implantada em produção.)

### deploy to the cloud

  (A empresa implantou a plataforma na nuvem.)

## Expressões comuns

- deploy an application
- deploy a service
- deploy an update
- deploy to production
- deploy to the cloud

## Erros comuns

❌ I have deploy the application.

✔ I have deployed the application.

No Present Perfect, utiliza-se o particípio **deployed**.

---

❌ We deployed in production.

✔ We deployed to production.

A expressão mais comum é **deploy to production**.

---

❌ She deploy the service every week.

✔ She deploys the service every week.

Na 3ª pessoa do singular, adiciona-se **-s**.

## Observações importantes

- **Deploy** é um dos verbos mais importantes na área de desenvolvimento de software, DevOps e Cloud Computing.
- As expressões mais comuns são:
  - **deploy an application**
  - **deploy a service**
  - **deploy an update**
  - **deploy to production**
  - **deploy to the cloud**
- No ambiente de TI, a palavra **deployment** aparece constantemente em pipelines CI/CD, Kubernetes, Docker, Azure, AWS e outras plataformas de infraestrutura.
