# Verbo: UPLOAD

## Traduções principais
- enviar
- fazer upload

### Informações gerais

**Outras traduções**
- carregar um arquivo
- transferir para um servidor
- publicar um arquivo online
- enviar dados para um sistema

#### Palavras da mesma família

- upload → upload / envio
- uploaded → enviado
- uploading → enviando
- uploader → carregador / usuário que faz upload

#### CEFR
- A2

#### Relevância para TI
- Extremamente usado

#### Tipo de verbo

- Regular

### Pronúncia (IPA – General American)

- Presente: **upload** → /ˌʌpˈloʊd/
- Presente (3ª pessoa): **uploads** → /ˌʌpˈloʊdz/
- Passado: **uploaded** → /ˌʌpˈloʊdɪd/
- Particípio: **uploaded** → /ˌʌpˈloʊdɪd/
- Forma em **-ING**: **uploading** → /ˌʌpˈloʊdɪŋ/

### Phrasal verbs

Não existem phrasal verbs realmente relevantes para **upload**.

### Forma em -ING

**upload → uploading**

O verbo apenas recebe **-ING**.

Exemplos:

- I am uploading a file.
  (Estou enviando um arquivo.)

- She is uploading a document.
  (Ela está fazendo upload de um documento.)

## Frases (tempo verbal)

### Presente (1ª pessoa)

I upload files every day.

(Eu envio arquivos todos os dias.)

### Presente (3ª pessoa)

She uploads reports to the system.

(Ela envia relatórios para o sistema.)

### Passado

I uploaded the document yesterday.

(Eu enviei o documento ontem.)

### Futuro

I will upload the new version later.

(Eu enviarei a nova versão mais tarde.)

### Particípio (Present Perfect)

I have uploaded the file.

(Eu enviei o arquivo.)

## Estruturas importantes

### Estrutura principal

**upload + objeto**

Exemplos:

- Upload the file.
  (Envie o arquivo.)

- I uploaded the image.
  (Eu enviei a imagem.)

- She uploaded the report.
  (Ela enviou o relatório.)

### Outras formas comuns

#### upload a file

- Please upload the file.
  (Por favor, envie o arquivo.)

- I uploaded the spreadsheet.
  (Eu enviei a planilha.)

- She uploaded the attachment.
  (Ela enviou o anexo.)

#### upload to

- Upload the document to the server.
  (Envie o documento para o servidor.)

- We uploaded the files to the cloud.
  (Enviamos os arquivos para a nuvem.)

- She uploaded the image to the website.
  (Ela enviou a imagem para o site.)

#### upload data

- The application uploads data automatically.
  (A aplicação envia dados automaticamente.)

- Sensors upload information every hour.
  (Os sensores enviam informações a cada hora.)

## Uso com outros verbos

### Usa -ING?

✔ Sim

Exemplos:

- Uploading files can take time.
  (Enviar arquivos pode levar tempo.)

- I enjoy uploading project updates.
  (Gosto de enviar atualizações de projetos.)

- They are uploading logs for analysis.
  (Eles estão enviando logs para análise.)

### Usa TO + infinitivo?

✔ Sim

Exemplos:

- I need to upload the report.
  (Preciso enviar o relatório.)

- We want to upload the new release.
  (Queremos enviar a nova versão.)

- She plans to upload the documentation.
  (Ela planeja enviar a documentação.)

### Preposição obrigatória?

Não possui.

Mas é comum:

- **upload to**

Exemplos:

- Upload the file to the server.
  (Envie o arquivo para o servidor.)

- Upload the image to the website.
  (Envie a imagem para o site.)

## Frases extras (uso real)

- Developers uploaded the logs for troubleshooting.
  (Os desenvolvedores enviaram os logs para análise de problemas.)

- Please upload the latest version of the document.
  (Por favor, envie a versão mais recente do documento.)

- The application uploads telemetry data automatically.
  (A aplicação envia dados de telemetria automaticamente.)

- We uploaded the deployment package to the server.
  (Enviamos o pacote de implantação para o servidor.)

- Users can upload files directly through the portal.
  (Os usuários podem enviar arquivos diretamente pelo portal.)

## Combinações mais comuns (Collocations)

### upload a file

- Please upload a file before submitting the form.
  (Por favor, envie um arquivo antes de enviar o formulário.)

### upload a document

- She uploaded the document successfully.
  (Ela enviou o documento com sucesso.)

### upload an image

- I uploaded an image to the website.
  (Eu enviei uma imagem para o site.)

### upload data

- The device uploads data every hour.
  (O dispositivo envia dados a cada hora.)

### upload to the cloud

- We uploaded the backups to the cloud.
  (Enviamos os backups para a nuvem.)

## Expressões comuns

- upload a file
- upload a document
- upload an image
- upload data
- upload to the cloud

## Erros comuns

❌ I have upload the file.

✔ I have uploaded the file.

No Present Perfect, utiliza-se **uploaded**.

---

❌ She upload reports every day.

✔ She uploads reports every day.

Na 3ª pessoa do singular, adiciona-se **-s**.

---

❌ Upload the file in the server.

✔ Upload the file to the server.

Com destino, normalmente utiliza-se **to**.

## Observações importantes

- **Upload** é o oposto de **download**.
- Em TI, é extremamente comum em contextos de arquivos, sistemas, APIs, nuvem e armazenamento.
- A estrutura mais frequente é **upload + objeto + to + destino**.
