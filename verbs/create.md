## Verbo: CREATE

### Traduções principais
- criar
- produzir

### Informações gerais

**Outras traduções**
- desenvolver
- gerar
- elaborar
- estabelecer

#### Palavras da mesma família

- creation → criação
- creator → criador
- creative → criativo
- creativity → criatividade
- created → criado

#### CEFR
- A1

#### Relevância para TI
- Muito usado

#### Tipo de verbo
- Regular

### Pronúncia (IPA – General American)

- Presente: **create** → /kriˈeɪt/
- Presente (3ª pessoa): **creates** → /kriˈeɪts/
- Passado: **created** → /kriˈeɪtɪd/
- Particípio: **created** → /kriˈeɪtɪd/
- Forma em **-ING**: **creating** → /kriˈeɪtɪŋ/

### Phrasal verbs

Não existem phrasal verbs muito relevantes derivados diretamente de **create**.

### Forma em -ING

**create → creating**

O **e** final é removido antes de adicionar **-ING**.

- create → creating

Pronúncia:

- creating → /kriˈeɪtɪŋ/

Exemplos:

- I am creating a new account.
  (Estou criando uma nova conta.)

- We are creating a new application.
  (Estamos criando uma nova aplicação.)

## Frases (tempo verbal)

### Presente (1ª pessoa)

I create reports every week.

(Eu crio relatórios toda semana.)

### Presente (3ª pessoa)

She creates useful tools.

(Ela cria ferramentas úteis.)

### Passado

I created a new database.

(Eu criei um novo banco de dados.)

### Futuro

I will create a new dashboard.

(Eu criarei um novo painel.)

### Particípio (Present Perfect)

I have created several projects.

(Eu criei vários projetos.)

## Estruturas importantes

### Estrutura principal

**create + objeto**

Exemplos:

- Create a new account.
  (Crie uma nova conta.)

- I created a document.
  (Eu criei um documento.)

- She created a project.
  (Ela criou um projeto.)

### Outras formas comuns

#### create + objeto + for + pessoa

Usado para indicar o destinatário.

- I created a report for the client.
  (Eu criei um relatório para o cliente.)

- We created a dashboard for managers.
  (Criamos um painel para gestores.)

- She created a guide for new employees.
  (Ela criou um guia para novos funcionários.)

#### create + problema/oportunidade

- The update created a problem.
  (A atualização criou um problema.)

- This change created new opportunities.
  (Esta mudança criou novas oportunidades.)

- The bug created unexpected behavior.
  (O bug criou um comportamento inesperado.)

#### create + from + objeto

- We created the report from raw data.
  (Criamos o relatório a partir de dados brutos.)

- She created the chart from the spreadsheet.
  (Ela criou o gráfico a partir da planilha.)

- The application created a file from the template.
  (A aplicação criou um arquivo a partir do modelo.)

## Uso com outros verbos

### Usa -ING?

- ✔ Sim

Exemplos:

- I enjoy creating software.
  (Eu gosto de criar software.)

- Creating documentation takes time.
  (Criar documentação leva tempo.)

- We are interested in creating new solutions.
  (Estamos interessados em criar novas soluções.)

### Usa TO + infinitivo?

- ✔ Sim

Exemplos:

- I want to create a website.
  (Eu quero criar um site.)

- We need to create a new user.
  (Precisamos criar um novo usuário.)

- She plans to create a training program.
  (Ela planeja criar um programa de treinamento.)

### Preposição obrigatória?

Não possui preposição obrigatória.

As combinações mais comuns são:

- create for
- create from
- create with

Exemplos:

- We created the solution for our customers.
  (Criamos a solução para nossos clientes.)

- The report was created from database records.
  (O relatório foi criado a partir de registros do banco de dados.)

- The application was created with Python.
  (A aplicação foi criada com Python.)

## Frases extras (uso real)

  (Os usuários devem criar uma conta primeiro.)

### create a project

- We created a project for the new client.
  (Criamos um projeto para o novo cliente.)

  (O sistema cria um relatório automaticamente.)

### create a database

  (O administrador criou um banco de dados ontem.)

### create a solution

  (A equipe criou uma solução para o problema.)

## Expressões comuns

- create an account
- create a project
- create a report
- create a solution
- create opportunities

## Erros comuns

❌ I have create a new database.

✔ I have created a new database.

No Present Perfect, utiliza-se o particípio **created**.

---

❌ The system create reports automatically.

✔ The system creates reports automatically.

Na 3ª pessoa do singular, adiciona-se **-s**.

---

❌ I created for the client a dashboard.

✔ I created a dashboard for the client.

A ordem mais natural é **create + objeto + for + pessoa**.

## Observações importantes

- **Create** é um dos verbos mais utilizados em desenvolvimento de software, bancos de dados e sistemas.
- A estrutura **create + objeto** é a mais importante para memorizar.
- Em TI, é extremamente comum em expressões como **create an account**, **create a database**, **create a report** e **create a project**.
