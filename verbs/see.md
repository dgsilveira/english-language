# Verbo: SEE

## Traduções principais
- ver
- entender

### Informações gerais

**Outras traduções**
- perceber
- observar
- encontrar
- compreender

#### Palavras da mesma família

- sight → visão
- seeing → vendo
- seen → visto
- unseen → não visto
- eyesight → visão

#### CEFR
- A1

#### Relevância para TI
- Muito usado

#### Tipo de verbo
- Irregular

### Pronúncia (IPA – General American)

- Presente: **see** → /siː/
- Presente (3ª pessoa): **sees** → /siːz/
- Passado: **saw** → /sɔː/
- Particípio: **seen** → /siːn/
- Forma em **-ING**: **seeing** → /ˈsiːɪŋ/

### Phrasal verbs

- see through
- see to
- see off
- see about

### Forma em -ING

**see → seeing**

O verbo apenas recebe **-ING**.

Pronúncia:

- seeing → /ˈsiːɪŋ/

Exemplos:

- I am seeing the results now.
  (Estou vendo os resultados agora.)

- We are seeing improvements.
  (Estamos vendo melhorias.)

## Frases (tempo verbal)

### Presente (1ª pessoa)

I see the problem.

(Eu vejo o problema.)

### Presente (3ª pessoa)

She sees the error message.

(Ela vê a mensagem de erro.)

### Passado

I saw the update yesterday.

(Eu vi a atualização ontem.)

### Futuro

I will see the report later.

(Eu verei o relatório mais tarde.)

### Particípio (Present Perfect)

I have seen this issue before.

(Eu já vi este problema antes.)

## Estruturas importantes

### Estrutura principal

**see + objeto**

Exemplos:

- I see the screen.
  (Eu vejo a tela.)

- She sees the notification.
  (Ela vê a notificação.)

- We see the results.
  (Nós vemos os resultados.)

### Outras formas comuns

#### see that + oração

- I see that the service is running.
  (Vejo que o serviço está em execução.)

- We see that the issue was fixed.
  (Vemos que o problema foi corrigido.)

- She sees that everything is working.
  (Ela vê que tudo está funcionando.)

#### see someone/something doing

- I saw him using the application.
  (Eu o vi usando a aplicação.)

- We saw the server restarting.
  (Vimos o servidor reiniciando.)

- She saw users reporting errors.
  (Ela viu usuários relatando erros.)

#### see a problem

- I see a problem in the configuration.
  (Vejo um problema na configuração.)

- The team saw a security issue.
  (A equipe identificou um problema de segurança.)

## Uso com outros verbos

### Usa -ING?

✔ Sim

Quando você vê uma ação acontecendo.

Exemplos:

- I saw him working.
  (Eu o vi trabalhando.)

- We saw the application loading.
  (Vimos a aplicação carregando.)

- She saw the system processing requests.
  (Ela viu o sistema processando requisições.)

### Usa TO + infinitivo?

✔ Sim

Normalmente na estrutura:

**see + objeto + verbo base**

Exemplos:

- I saw him leave.
  (Eu o vi sair.)

- We saw the service start.
  (Vimos o serviço iniciar.)

- She saw the application crash.
  (Ela viu a aplicação falhar.)

### Preposição obrigatória?

Não possui.

Exemplos:

- See the report.
  (Veja o relatório.)

- See the logs.
  (Veja os logs.)

- See the results.
  (Veja os resultados.)

## Frases extras (uso real)

- I can see the changes in the latest version.
  (Consigo ver as alterações na versão mais recente.)

- We saw several errors in the logs.
  (Vimos vários erros nos logs.)

- The administrator saw unusual network traffic.
  (O administrador observou tráfego de rede incomum.)

- Users can see their notifications on the dashboard.
  (Os usuários podem ver suas notificações no painel.)

- I see what caused the issue now.
  (Agora eu entendo o que causou o problema.)

## Combinações mais comuns (Collocations)

### see a problem

- I can see a problem with the configuration.
  (Consigo ver um problema na configuração.)

### see the results

- We can already see the results.
  (Já conseguimos ver os resultados.)

### see an error

- The developer saw an error in the code.
  (O desenvolvedor viu um erro no código.)

### see a change

- Users immediately saw a change in performance.
  (Os usuários perceberam imediatamente uma mudança no desempenho.)

### see what happened

- Let's see what happened.
  (Vamos ver o que aconteceu.)

## Expressões comuns

- see you later
- see the point
- see what happens
- see for yourself
- wait and see

## Erros comuns

❌ I have saw this issue.

✔ I have seen this issue.

O particípio correto é **seen**.

---

❌ Yesterday I seen the report.

✔ Yesterday I saw the report.

No passado simples, utiliza-se **saw**.

---

❌ She see the error.

✔ She sees the error.

Na 3ª pessoa do singular, adiciona-se **-s**.

## Observações importantes

- As formas corretas são: **see → saw → seen**.
- **See** pode significar tanto "ver" quanto "entender", dependendo do contexto.
- Em TI, aparece frequentemente em expressões como **see the logs**, **see the results**, **see an error** e **see what happened**.
