## Verbo: LEARN

### Traduções principais
- aprender

### Informações gerais

**Outras traduções**
- estudar
- adquirir conhecimento
- descobrir
- ficar sabendo

#### Palavras da mesma família

- learning → aprendizado
- learner → aprendiz
- learned → aprendido
- knowledgeable → instruído
- lifelong learning → aprendizado contínuo

#### CEFR
- A1

#### Relevância para TI
- Extremamente usado

#### Tipo de verbo
- Regular

### Pronúncia (IPA – General American)

- Presente: **learn** → /lɝːn/
- Presente (3ª pessoa): **learns** → /lɝːnz/
- Passado: **learned** → /lɝːnd/
- Particípio: **learned** → /lɝːnd/
- Forma em **-ING**: **learning** → /ˈlɝːnɪŋ/

> Em inglês britânico, também é comum: **learnt**.

### Phrasal verbs

- learn about
- learn from

### Forma em -ING

**learn → learning**

O verbo apenas recebe **-ING**.

- learn → learning

Pronúncia:

- learning → /ˈlɝːnɪŋ/

Exemplos:

- I am learning Python.
  (Estou aprendendo Python.)

- She is learning English.
  (Ela está aprendendo inglês.)

---

## Frases (tempo verbal)

### Presente (1ª pessoa)

I learn something new every day.

(Eu aprendo algo novo todos os dias.)

### Presente (3ª pessoa)

She learns quickly.

(Ela aprende rapidamente.)

### Passado

I learned a lot from that project.

(Eu aprendi muito com aquele projeto.)

### Futuro

I will learn more about cloud computing.

(Eu aprenderei mais sobre computação em nuvem.)

### Particípio (Present Perfect)

I have learned many useful skills.

(Eu aprendi muitas habilidades úteis.)

---

## Estruturas importantes

### Estrutura principal

**learn + objeto**

Exemplos:

- Learn English.
  (Aprenda inglês.)

- I learned Python.
  (Eu aprendi Python.)

- She learned the process.
  (Ela aprendeu o processo.)

### Outras formas comuns

#### learn to + infinitivo

Muito comum.

- I learned to drive.
  (Eu aprendi a dirigir.)

- She learned to code.
  (Ela aprendeu a programar.)

- We learned to use the platform.
  (Aprendemos a usar a plataforma.)

#### learn about + assunto

- I am learning about AI.
  (Estou aprendendo sobre IA.)

- She learned about cybersecurity.
  (Ela aprendeu sobre segurança cibernética.)

- We learned about cloud architecture.
  (Aprendemos sobre arquitetura de nuvem.)

#### learn from + pessoa/experiência

- I learned from my mistakes.
  (Aprendi com meus erros.)

- We learned from the incident.
  (Aprendemos com o incidente.)

- She learned from experienced developers.
  (Ela aprendeu com desenvolvedores experientes.)

---

## Uso com outros verbos

### Usa -ING?

- ✔ Sim

Exemplos:

- Learning English takes time.
  (Aprender inglês leva tempo.)

- I enjoy learning new technologies.
  (Eu gosto de aprender novas tecnologias.)

- She is learning how to code.
  (Ela está aprendendo a programar.)

### Usa TO + infinitivo?

- ✔ Sim

Exemplos:

- I want to learn Python.
  (Quero aprender Python.)

- We need to learn Kubernetes.
  (Precisamos aprender Kubernetes.)

- She plans to learn data analysis.
  (Ela planeja aprender análise de dados.)

### Preposição obrigatória?

Não possui preposição obrigatória.

Mas são muito comuns:

- learn about
- learn from

Exemplos:

- Learn about cloud computing.
  (Aprenda sobre computação em nuvem.)

- Learn from mistakes.
  (Aprenda com os erros.)

## Erros comuns

❌ I have learn a lot.

✔ I have learned a lot.

No Present Perfect, utiliza-se o particípio **learned**.

---

❌ She learn Python quickly.

✔ She learns Python quickly.

Na 3ª pessoa do singular, adiciona-se **-s**.

---

❌ I learned about to code.

✔ I learned to code.

✔ I learned about programming.

Não misture **learn to** e **learn about**.

---

## Observações importantes

- **Learn** é um dos verbos mais importantes para estudantes e profissionais.
- Estruturas essenciais:
  - **learn + objeto**
  - **learn to + verbo**
  - **learn about + assunto**
  - **learn from + experiência**
- Em TI, é extremamente comum em expressões como:
  - **learn programming**
  - **learn Python**
  - **learn cloud computing**
  - **learn from incidents**
  - **keep learning**
- A expressão **keep learning** significa **"continue aprendendo"** e é muito utilizada no desenvolvimento profissional.
