# Template para estudo de verbos

Cada verbo deve seguir um padrão consistente.

O objetivo do template é estudar não apenas o significado do verbo, mas também:

* conjugação;
* pronúncia;
* estruturas;
* uso com `-ING`;
* uso com `TO + infinitive`;
* preposições;
* phrasal verbs;
* collocations;
* erros comuns;
* aplicação prática.

---

## Como solicitar um novo verbo para a IA

Ao solicitar ajuda para criar um novo arquivo, forneça o verbo e utilize o template abaixo como referência.

A resposta deve:

* utilizar inglês americano (General American);
* utilizar AFI/IPA para a pronúncia;
* informar o nível CEFR;
* informar a relevância para TI;
* informar se o verbo é regular ou irregular;
* analisar a forma em `-ING`;
* informar phrasal verbs relevantes;
* apresentar as principais estruturas;
* explicar o uso com `-ING` e `TO + infinitive`;
* informar preposições obrigatórias, quando houver;
* apresentar frases simples e naturais;
* sempre apresentar as traduções;
* destacar erros comuns;
* evitar informações desnecessárias ou exemplos artificiais.

# Critérios para os exemplos

As frases devem ser:

* simples;
* naturais;
* fáceis de entender;
* preferencialmente entre A1 e B1;
* úteis para conversação;
* úteis para o ambiente profissional;
* relacionadas a TI quando isso fizer sentido.

Evitar frases excessivamente complexas apenas para demonstrar conhecimento.

O objetivo é **memorizar o uso do verbo**, e não tornar a revisão cansativa.
