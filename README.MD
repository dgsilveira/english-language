# English Language

Repositório pessoal de estudos e revisão do idioma inglês.

Este projeto tem como objetivo construir uma base de conhecimento organizada para estudar, revisar e consolidar o inglês ao longo do tempo.

O conteúdo é desenvolvido principalmente com foco no inglês americano (American English), considerando também aplicações práticas no ambiente profissional e, quando relevante, na área de tecnologia e desenvolvimento de software.

---

## Objetivos

* Desenvolver vocabulário em inglês.
* Aprender e revisar verbos de forma estruturada.
* Consolidar estruturas gramaticais.
* Melhorar leitura e compreensão.
* Melhorar pronúncia e comunicação.
* Aprender combinações naturais de palavras (collocations).
* Identificar erros comuns de brasileiros aprendendo inglês.
* Construir uma base de conhecimento que possa ser revisada continuamente.

---

## Método de estudo

O projeto foi pensado para revisão recorrente.

A revisão do conteúdo pode envolver:

* copiar frases à mão;
* ler as frases em voz alta;
* falar as frases;
* revisar vocabulário;
* revisar estruturas gramaticais;
* repetir o conteúdo periodicamente.

A intenção é que o conhecimento seja reforçado por exposição e repetição ao longo do tempo, e não apenas estudado uma única vez.

# Padrão de revisão

A revisão do conteúdo deve priorizar:

1. leitura;
2. compreensão;
3. pronúncia;
4. fala;
5. escrita;
6. repetição periódica.

O conteúdo será revisado aproximadamente uma vez a cada 30 dias.
